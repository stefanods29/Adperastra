# Adperastra 0.1.0-preview.1 — Versión preliminar de Office

Descarga **Adperastra-0.1.0-preview.1-windows-x64-portable.zip**, verifica su suma con **SHA256SUMS.txt**, extrae todo el ZIP en una carpeta donde puedas escribir e inicia **Adperastra.exe**. Necesitas Windows 11 x64, WebView2 y el runtime Microsoft Visual C++ x64. El README incluye los enlaces oficiales. El ZIP incluye el motor firmado de Office y fuentes compatibles; no necesitas instalar LibreOffice por separado.

El botón **+** abre otra pestaña Inicio para explorar carpetas independientes. Los archivos de Office se abren primero en vista previa. Elige **Habilitar edición** para modificar texto compatible directamente sobre páginas DOCX o diapositivas PPTX, o valores de celdas XLSX en la cuadrícula. Entrar aplica el texto y Escape cancela. **Guardar una copia** o Ctrl+S crea otro archivo sin modificar el original.

Las páginas admiten desplazamiento continuo y zoom. En el área de diapositivas, usa Izquierda/Derecha o Re Pág/Av Pág. Consulta el README incluido para ver las instrucciones completas.

Esta versión preliminar todavía no ofrece edición avanzada de formato, objetos, cálculo de fórmulas, todos los formatos de visualización de hojas ni edición de archivos antiguos. El motor y las fuentes compatibles pueden mostrar diferencias respecto de Microsoft Office. El ejecutable de Windows no tiene certificado Authenticode; la firma del paquete de Office es independiente. No se incluyen modelos de IA, claves de API ni el motor multimedia. Los ZIP automáticos de código fuente de GitHub no incluyen la aplicación ejecutable ni el paquete de Office.

El paquete se genera limpio, sin datos personales, historial ni perfiles del desarrollador. Conserva toda la carpeta extraída. Para actualizar esta versión preliminar, extrae la nueva versión en otra carpeta y conserva la anterior hasta comprobarla.
