# Sort suggestions
Review destinations without automatic moves.

## How to use it
Choose approved destination folders in **Settings > AI**. A suggestion can offer **Move**, **Not now** or **Never for this kind**. **Move** opens the normal file-operation preview. Only confirmed ordinary moves contribute local extension counts; sensitive moves are excluded. **Reset destination history** is in Settings. API reasoning sends only the displayed content after a separate one-time Send confirmation.

See also: "Moving files" and "AI privacy".
