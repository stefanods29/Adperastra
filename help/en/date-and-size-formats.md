# Date and size formats

Display dates, numbers and file names in a consistent way.

## How to use

Open **Settings > Date and size formats**. Choose a locale, date style, time format and decimal or binary sizes. A custom date pattern accepts only the listed fields. Choose middle or end truncation for long names.

## Good to know

These options do not rename files or change sort values. Existing settings keep their previous size labels until changed.

See also: "Tab options".
