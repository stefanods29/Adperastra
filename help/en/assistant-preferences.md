# Assistant preferences and privacy

Choose how the assistant answers and which sources it can read.

## How to use it

Open **Assistant preferences**. Set its name, answer length, tone and language. Choose low-risk automatic actions, content-reading permission and folders it must never access. Wider folder access requires **Allow** in its separate prompt. History starts off; enable **Keep encrypted chat history** only if wanted. Use **Clear chat history…** to remove saved chats.

## Good to know

Read permission does not permit sending a file online. API requests with source content show the exact content and provider before **Send this content**. Keys are stored separately from settings and cannot be read back. Locked or sensitive content cannot be sent to an API.
