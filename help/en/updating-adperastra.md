# Updating Adperastra

Check for a newer version when you choose to, read what changed, and open the checked release page.

## How to use

- Update checks are off unless you enable them or choose **Check now**.
- Read **What's new** and open the checked GitHub release page.
- Downloads and installation require your choice.

## Good to know

- No document or diagnostic data is uploaded.
- Keep a backup and close safely before upgrading.
- Upgrading keeps your settings and files.
- Adperastra does not install an update automatically.

See also: "App storage".
