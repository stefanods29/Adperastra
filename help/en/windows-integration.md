# Windows Explorer integration

Add optional Adperastra commands to Windows Explorer. The classic menu and the Windows 11 main menu are separate choices.

## How to use

- Open **Settings > Windows integration** to add optional commands.
- **Add commands under Show more options** uses Windows' classic menu.
- Use **Choose default apps…** to open Windows Settings; you make the default choice there.

## Good to know

- The main Windows 11 menu needs a supported package identity and trusted deployment, so it is shown separately and may be unavailable.
- **Convert to…** opens Adperastra's review dialog; it does not change files immediately.
- Disable integration here to remove only Adperastra's own entries. Entries another program changed are left alone.

See also: "File associations".
