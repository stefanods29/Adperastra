# The command bar

The command bar sits under the address bar and holds the actions you use most. Hover a button to see its name and keyboard shortcut.

## The buttons, from left to right

- **New**: create a folder or a text file.
- **Cut**, **Copy**, **Paste**, **Rename**, **Share**, **Delete**: work with the selected items. Buttons that need a selection stay grayed out until you select something.
- **Sort**: sort by name, date modified, type, or size, ascending or descending, and **Group by** one of them (for example, by date: Today, Yesterday, Earlier this week...).
- **View**: show or hide the **Details pane**, **Hidden items**, **File name extensions**, and **Item check boxes**. These choices are saved.
- **See more** (•••): **Select all**, **Select none**, **Invert selection**, **Pin folder**, **Copy as path**, **Open in Terminal**, and **Properties**.
- **Details**: show or hide the Details pane.
- **?**: open this help page.

When the window is narrow, buttons that don't fit move into **See more**.

## Coming in later versions

**New**, **Cut**, **Copy**, **Paste**, and **Delete** arrive in the next version, together with undo and progress for big copies. The **List** and icon views under **View** arrive later. Until then they are shown but grayed out.
