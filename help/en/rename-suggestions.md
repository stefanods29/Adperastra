# Rename suggestions
Suggest clearer names from selected file content.

## How to use it
Choose **Suggest a name**, review the pattern and edit or exclude each proposed stem. Review the ordinary bulk-rename preview before executing. Extensions and source files remain unchanged until that explicit action.

## Good to know
Content may be misunderstood. API reasoning sends only the displayed content after a separate one-time Send confirmation.

See also: "Bulk rename" and "AI quality tiers".
