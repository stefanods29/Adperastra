# Customizing toolbars

Choose which registered commands appear where you work.

## How to use

Open Settings > Customize toolbars. Choose a bar, add or remove commands and use Move up or Move down. Review the preview and Apply. Quick Access holds frequently used commands; Classic menu bar offers File, Edit, View, Tools and Help.

## Good to know

Hiding a command does not remove it from the command palette. A custom control can move only between compatible groups. Cancel leaves your saved layout unchanged.

See also: "Keyboard shortcuts and styles" and "Moving toolbars and panels".
