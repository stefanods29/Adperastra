# Checking spelling

Check spelling with an available local checker.

## How to use

Open **Review** and choose **Spelling**. Review a marked word and choose a suggestion, or leave it unchanged.

## Good to know

The checker uses the document language and installed local support. Dictation is a separate explicit speech-pack action; AI grammar/style suggestions arrive in20c and online requests require17a API payload consent. A suggestion changes text only when you choose it.

See also: "Editing documents" and "Languages".
