# Files in use

See which programs Windows reports as holding a file.

## How to use

Choose **What is using this?**. Review the program list. Save your work in a listed program before choosing **Ask program to close**, then confirm. Return and choose **Retry action**.

## Good to know

The app never forces a program to stop. Protected programs cannot be closed here. Folder checks do not inspect every file inside. An empty list does not prove the file can be changed.

See also: “Copying and conflicts” and “Saving files”.
