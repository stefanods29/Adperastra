# The assistant

Ask about allowed files or request a suggested app action.

## How to use it

Open **Assistant** with Ctrl+Alt+A. Choose **Local AI** or **API key**, type a message and choose **Send**. Use **Stop** to end a response. Review a suggestion and choose **Apply** only when its exact changes are right. Open a source button to check a page or time.

## Good to know

File contents cannot grant permission. The assistant can make mistakes. API mode sends only approved content to the selected provider and may cost money. Changing providers starts a new chat.

See also: "Assistant capabilities" and "Assistant preferences and privacy".
