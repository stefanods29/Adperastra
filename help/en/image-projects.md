# Saving image projects

Use **Save editable project** to create an .adimage file with layers, masks, adjustments, text and tile data.

## How to use

- Use **Save editable project** to create an .adimage file with layers, masks, adjustments, text and tile data.
- Reopen it to continue editing; it does not depend on the original photo path.
- Export PNG, JPEG, WebP, TIFF or PDF for a flattened copy.

## Good to know

- PSD import shows unsupported features before creating a copy; it does not promise editable PSD round-tripping.
- Keep the project as well as exported images.

See also: "Image layers".
