# Opening files from Windows

Open supported files in the Adperastra window already running.

## How to use it

- Choose Adperastra in Windows **Open with**.
- The app checks the files and opens tabs using your normal opening preferences.

## Good to know

- This does not change your default apps.
- Registration options arrive with Windows integration.
- A refused or busy request does not change files.

See also: "Opening files" and "Default apps".
