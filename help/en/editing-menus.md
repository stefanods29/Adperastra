# Editing menus

Arrange registered commands without changing what they do.

## How to use

Open Settings > Edit menus. Choose a target, hide or reorder items, create submenus or separators and review the preview. Apply or reset that menu.

## Good to know

Preview does not run commands. Hidden menu commands remain in the command palette when available. Setups cannot add scripts.

See also: "Customizing toolbars".
