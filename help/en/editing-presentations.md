# Editing presentations

Edit a supported slide deck locally. Open the file and enable editing when offered. Select a slide in the left pane, then use Home or Insert to edit its text and objects. Use Notes below the slide for speaker notes. Save keeps supported changes; Save a copy creates another file. Imported unsupported content is preserved when safe saving is available.

## Good to know

- Unsupported imported effects and objects are kept as preserved content, not erased by an ordinary save.
- If safe preservation is unavailable, saving that file is refused. Use a supported copy or open it in your chosen app.
- Locked-folder content stays in memory; a plaintext recovery copy is never written for it.

See also: "Layouts and themes" and "Presenting".
