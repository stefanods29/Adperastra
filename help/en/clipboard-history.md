# Clipboard history

Reuse recent copies without changing their source files.

## How to use

Open **Clipboard history**, search or choose an item and select **Paste selected item**. Pin an item to keep it while the history fills. Clear references you no longer need.

## Good to know

History stays in memory by default. Windows-wide capture and encrypted persistence are separate choices. Items marked private are skipped. Clearing history does not delete source files or clear the current Windows clipboard.
