# Searching photos by content
Find local photos by describing their contents.

## How to use it
Enable **Photos by content** and select indexed folders in **Settings > AI**. Choose **Photos by content** in Search, type a description and search. Results show relevance and indexing coverage. Online-only and sensitive files are excluded.

## Good to know
No file is uploaded. API reasoning sends only the displayed content after a separate one-time Send confirmation.

See also: "Similar files" and "Indexing and privacy".
