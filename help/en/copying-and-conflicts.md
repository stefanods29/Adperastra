# Copying and conflicts

Copy or move files while keeping control of long tasks.

## How to use

Start a copy or move and open its transfer window. Use **Pause**, **Resume**, **Skip file** or **Cancel**. When a name is already in use, compare both items and choose **Skip**, **Keep both**, or **Merge folders** when offered.

## Good to know

Completed files remain if you cancel. Replacing existing files is unavailable until the exact existing file can be protected. Undo can refuse if an item changed outside the app; it keeps the files instead of guessing.

See also: "Files in use" and "The job queue".
