# Converting files

Make a new file in another format.

## How to use

Select files and choose **Convert to…**. Choose an output format, review the preview and options, then select an output folder. Review any listed quality, transparency, animation or metadata changes. Choose **Convert**. Use Cancel to stop remaining work.

## Good to know

- Your original files are kept.
- Existing files are not replaced.
- Some formats cannot keep every kind of metadata.
- A file that already finished remains available if you cancel the rest.
- Unsaved edits are captured for that export without saving over the original.

PDF, document, table and archive choices appear when compatible.

Use **Page range** to choose PDF pages and **Sheet** to choose workbook data. Text cells that could act as formulas need the displayed safety prefix. Formulas are not evaluated here.
