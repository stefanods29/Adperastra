# Assistant models and hardware

Choose a local model or the Meta API.

## How to use it

Local models are optional packs in **App storage**. Smaller models need less memory; the recommended size is a starting point. To use Meta, choose **API key**, select **Enter or change key…**, then **Test connection** and a supported model. Review possible provider charges. To use a model already running locally, select **Model I already run** and its loopback address and port.

## Good to know

Bundled local processing stays on this computer. A separate local server may forward content. API mode uses the network only for requests you approve. Errors stop the request; choosing Local AI or retrying is your decision. A retry may cost money. No model is downloaded or account purchased automatically.

See also: "AI packs and hardware" and "Assistant preferences and privacy".
