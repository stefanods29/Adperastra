# Similar files
Find indexed files with related content.

## How to use it
Select one photo or document, choose **Similar files** and review the results. Photos compare image content; documents compare opted-in extracted text. Similarity does not prove duplicate identity. An unlocked source requires separate one-time memory consent and is never indexed. API reasoning sends only the displayed content after a separate one-time Send confirmation.

See also: "Searching photos by content" and "Duplicate finder".
