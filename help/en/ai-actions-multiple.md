# AI actions for multiple files

Select two readable documents and choose Compare documents. Review references to both sides of each difference. For a folder, choose Summarize this folder, review the file list, and explicitly choose whether to include contents and subfolders. Confirm the list before generation. Review the sources, skipped files and partial or file-names-only notice.

## How to use it

The app reads only the approved scope. File names alone do not establish what a file contains. A folder summary includes at most 100 approved files; a smaller approved scope is required when it exceeds the displayed limit. Generation never renames, moves, deletes or edits those files. With an API backend, file names and readable excerpts require a separate review and Send; an earlier folder permission does not approve an upload.
