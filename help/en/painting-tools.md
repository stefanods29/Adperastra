# Painting tools

Choose **Brush**, **Erase**, **Fill**, **Gradient** or **Clone stamp** to paint directly on the image.

## How to use

- Choose **Brush**, **Erase**, **Fill**, **Gradient** or **Clone stamp**.
- Set size, hardness, opacity, flow and spacing; a pen can control size by pressure.
- Alt-click sets the clone source.

## Good to know

- Each completed stroke is one undoable change.
- Selection masks restrict affected pixels.
- These tools are deterministic and use no AI model.

See also: "Image selections".
