# Setup and first run

When you start Adperastra, a small setup program checks that everything the app needs is present on your PC. If everything is there, you see nothing: the app just starts.

The first time you run Adperastra, it asks three things, once only:

1. **Language** - English or Spanish (Latin America). You can change it later in Settings.
2. **Theme** - Light, Dark, or Follow Windows.
3. **Optional packs** - extra downloads that enable extra features, such as the Office engine or AI tools. Nothing is selected for you. Each pack shows what it enables and how much it downloads. Until the pack manager arrives in a later version, the packs you choose are saved and marked "Available in a later version".

After that first run, packs can be added or removed only in Settings > App storage.

If a needed component is missing or damaged, the setup window explains what it is installing and shows progress. Nothing is installed without showing you first. Everything the setup program does is written to a local log file; nothing is sent anywhere.
