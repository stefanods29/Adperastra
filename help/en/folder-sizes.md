# Folder sizes

Load optional folder totals without blocking browsing.

## How to use

Enable Calculate folder sizes in the background and show the Size column or Details pane. Network folders require their own opt-in.

## Good to know

Calculating values sort after known sizes. Partial values say At least. Hiding the feature stops unused work. Online-only content is not downloaded.

See also: "Background work" and "Folder columns".
