# Layouts and themes

Keep slides consistent without discarding content. Select slides and choose Layout for a placement pattern, or Theme for colors, fonts and layouts. Review any overflow before confirming. Masters define reusable defaults. Manual formatting and objects without matching placeholders are retained. Style library provides additional manual choices when available.

## Good to know

- A layout never deletes an object to make the slide fit. Review unmatched or overflowing content before you confirm.
- A theme change is one Undo step and leaves manual formatting in place.
- Imported master data that the engine cannot edit is preserved as opaque content.

See also: "Editing presentations" and "The style library".
