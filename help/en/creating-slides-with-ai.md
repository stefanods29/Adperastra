# Creating slides with AI

Turn selected source material into a reviewed draft made from real slide layouts.

## How to use

Choose Create slides from a document, outline or notes, pick a style and a slide count, then review the structured outline. You can also add a slide, shorten selected text, write speaker notes, suggest a layout or suggest a style. Edit the outline, review its real slide preview and fix overflow or changed facts. Accept draft creates an unsaved presentation with Undo; other actions change only their reviewed scope. Choose Save a copy to create a separate file.

## Good to know

The model supplies text and image suggestions; the app builds the actual slides. Images are not downloaded automatically. Check facts, names, numbers and source anchors. An API backend requires a separate payload preview and one-time Send consent, followed by a separate Accept action. Sensitive unlocked content is not sent. Styles can be changed later with one Undo. No automatic training runs.
