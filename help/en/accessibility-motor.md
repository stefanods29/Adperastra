# Motor accessibility

Use the keyboard or pick and drop without holding a drag.

## How to use

Adjust click and hover delays and drag distance. Choose Pick up selection, choose a destination, then Drop selection; Esc cancels. Larger targets help pointer use.

## Good to know

Normal file confirmations still apply. No action requires a timed key hold. Windows Sticky Keys, Voice Access and on-screen keyboards can use named controls.

See also: "Keyboard shortcuts and styles".
