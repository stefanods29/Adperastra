# Indexing and privacy

Control which local names and text are stored.

## How to use

- Add only folders you want indexed.
- Enable contents and OCR separately.
- Pause, rebuild or remove an indexed folder in **Settings**.

## Good to know

- The index stays in this profile with a size limit.
- Sensitive unlocked content is excluded.
- Removing index data does not remove your files.
- Optional NTFS permission is not needed for normal browsing.

See also: "App storage".
