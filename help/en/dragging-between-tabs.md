# Dragging between tabs

Move between views while holding a file drag.

## How to use it

- Hold files over a tab until it opens.
- Drop on a folder to use the normal copy or move action.
- Drop on the tab bar to open files, or on a group to open them there.

## Good to know

- A file editor accepts only supported insertions.
- If several actions are possible, choose one before anything changes.
- Change the hover delay in Settings.

See also: "Copying content between tabs" and "Tab groups".
