# Extracting tables

Review a detected table before creating a spreadsheet.

## How to use it

Choose **Tables to spreadsheet**, select a table and correct headers and cells. Split or merge columns in the preview, then export to XLSX or CSV.

## Good to know

Formula-like text remains literal text. A source label helps find the original; it does not prove the extracted value is correct. With an API backend, review the displayed scan content and confirm Send once before inference.

See also: "Turning scans into documents" and "Converting files".
