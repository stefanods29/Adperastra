# Managing tags

Keep a reusable catalog of named labels.

## How to use

- Open Manage tags to create, rename, merge, delete, import or export tags.
- Review conflicts before importing.
- Personal locations are excluded from exports unless selected.

## Good to know

- Deleting a tag does not delete files.
- Merge and delete support Undo within the retained history limit.

See also: "Tags" and "Smart folders".
