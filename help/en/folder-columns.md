# Folder columns

Choose the details shown for each folder.

## How to use

Right-click a Details column heading and choose **Choose columns…**. Show the columns you need, move them up or down and resize their headings. Use **Restore default columns** to return to the original four.

## Good to know

The Name column stays visible. Extra metadata is loaded only when needed. Remembered folder views include sorting and grouping when enabled.

See also: "View modes" and "Rich file information".
