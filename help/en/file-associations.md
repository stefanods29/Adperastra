# File associations

Choose which file families offer Adperastra in **Open with**, without changing your default apps.

## How to use

- Open **Settings > Windows integration** and select the file families you want Adperastra to offer in **Open with**.
- Use **Choose default apps…** to make your own choices in Windows Settings.

## Good to know

- Installing Adperastra never silently replaces your default apps.
- Uninstall removes matching app-owned entries and preserves choices changed by another program.
- Turning off a family removes only Adperastra's own entry for it.

See also: "Windows Explorer integration".
