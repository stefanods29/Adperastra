# Safe mode

Start with temporary defaults after repeated startup failures.

## How to use

Review the safe-mode banner. Packs and background features stay disabled. Save any work, then choose **Restart normally** when you are ready to try your saved configuration.

## Good to know

Safe mode keeps your original settings and files. Resetting settings is a separate explicit action.

See also: "Recovering after a crash" and "Reporting a problem".
