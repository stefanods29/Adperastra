# Quick preview

Look inside a file without opening another tab.

## How to use

- Select a file and press **Space**.
- Use **Left** and **Right** to view nearby files.
- Press **Space** or **Escape** to close the preview.
- Choose **Open** to open the file normally.

## Good to know

- Previews do not edit your files.
- Online-only files show a cloud notice until you choose Open.
- Some formats have no preview yet.

See also: "Opening files" and "File details".
