# Reporting a problem

Prepare a local diagnostic file you can review before sharing.

## How to use

Open **Report a problem**. Review the included files, edit or exclude text, and keep paths and user names masked. Choose **Save diagnostics ZIP…**. If you want to report it, choose **Open issue page** and attach the ZIP yourself.

## Good to know

Nothing uploads automatically. Masking may miss information, so review it. Crash dumps are excluded by default and can contain private data.

See also: "Safe mode" and "Recovering after a crash".
