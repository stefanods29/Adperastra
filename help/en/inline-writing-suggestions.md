# Writing suggestions

Optional completions appear after you pause typing.

## How to use it

Enable **Inline writing suggestions** and the desired file types in Settings > AI. A gray completion can appear at a collapsed cursor. **Tab** accepts a current suggestion and **Escape** dismisses it. Typing or moving the cursor cancels it immediately.

## Good to know

Suggestions start off, remain plain text and never save or execute themselves. Undo reverses one accepted suggestion. Suggestions require Local AI; an API backend cannot be authorized by a typing pause.
