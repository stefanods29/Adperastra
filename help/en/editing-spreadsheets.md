# Editing spreadsheets

Edit a supported workbook locally.

## How to use

Open the file, enable editing when offered, and select a cell. Type a value or use the formula bar. Enter confirms and Escape cancels the current edit. Sheet tabs add, rename or reorder sheets. **Save** keeps supported changes; **Save a copy** creates a separate file.

## Good to know

External connections and macros do not run.

See also: "Formulas" and "File compatibility and limits".
