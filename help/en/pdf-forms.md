# Filling PDF forms

Enable editing and select a supported text, checkbox, radio or choice field. Enter a value and save a copy.

## Good to know

Calculations and document scripts never run. XFA, signature and unsupported rich-text fields remain read-only; Adperastra does not flatten them silently. Reopen the copy in your other PDF app to inspect important forms.

See also: Signing a PDF visually.
