# Editing documents

Edit a supported document with local controls.

## How to use

Open the file and choose **Enable editing** when offered. Type in the document and use **Home** to format the selection. Choose **Save** to keep changes in the same supported file, or **Save a copy** to create a separate file.

## Good to know

AutoSave starts off and can be enabled only when safe saving is available. Files from the internet start in protected view. **Compatibility and limits** explains unsupported content.

See also: "Formatting and styles" and "Unsaved changes and recovery".
