# Formatting and styles

Keep formatting consistent.

## How to use

Select text for font controls, or select paragraphs for alignment, spacing and styles. Choose a style from **Home**; use **Create style** for a reusable local document style. **Layout** changes the current section's page size, margins and columns.

## Good to know

A blank or mixed control means the selection contains different values. Opening a picker does not apply a value.

See also: "Editing documents" and "File compatibility and limits".
