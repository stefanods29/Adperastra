# Folder backgrounds

Show an optional readable background behind folder items.

## How to use

Enable **Show folder backgrounds** in **Settings**. In **Customize folder** choose a solid color, gradient or image and adjust opacity or blur. Choose whether subfolders inherit it.

## Good to know

Backgrounds are off by default, cached locally and dimmed when text needs more contrast. Hiding them does not delete the original image.

See also: "Customizing folders".
