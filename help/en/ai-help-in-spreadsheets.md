# AI help in spreadsheets

Review calculated formulas and typed changes before editing a workbook.

## How to use it

Select one range and choose an AI action. **Write a formula that…** proposes one formula, checks its supported functions and references, then calculates it on a separate copy before insertion. Review its canonical form, localized form and actual result. **Explain this formula** and **Describe this table** produce read-only text. **Clean this data** shows every before-and-after cell change; choose explicit date and number rules. **Suggest a chart** renders a real chart from the selected cells. Accept only the changes you reviewed.

## Good to know

External connections, volatile or blocked formulas and macros do not run. Ambiguous dates and leading-zero identifiers are not guessed. Duplicate rows are marked first; rows are never deleted by cleaning. Choosing an API backend requires a separate preview and one-time **Send** consent for the displayed cell content. Acceptance still requires another explicit action. Undo reverses one accepted transaction. Check results yourself.
