# Search modes and prefixes

Choose what a query searches.

## How to use

- Select **Name**, **Content**, **Filters** or **Regex**.
- **Ctrl+Tab** changes modes while the search box has focus.
- Prefixes `name:`, `text:` and `re:` select a mode.

## Good to know

- Optional AI modes become available only after their separate opt-ins and local packs are ready.
- Content searching requires explicit indexing consent.

See also: "Indexing and privacy".
