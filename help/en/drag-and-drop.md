# Drag and drop

Drag files and folders with the mouse, inside Adperastra and between Adperastra and other apps.

## Dragging

- Drag items onto a folder in the list, a folder in the navigation pane, or a part of the address bar to copy or move them there.
- A small label follows the pointer and says what will happen, for example "Move to Documents".
- Dropping on empty space in the same folder does nothing.

Like Windows:

- Dragging within the same drive moves; dragging to another drive copies.
- Hold **Ctrl** to copy, **Shift** to move, or **Alt** to create a shortcut in the folder you drop on.

## With other apps

- Drag files from Windows Explorer or the desktop into a folder here to copy or move them (the same key rules apply).
- Drag files from here onto Windows Explorer, the desktop, or another app that accepts files.

Every drop runs like a copy or move: name conflicts ask first, progress shows for big operations, and you can undo it afterwards.

When you move files out of here into another app, that app does the work, so the move can't be undone from here. Undo it in that app (for example Ctrl+Z in Windows Explorer). If the originals had to be removed here, they went to the Recycle Bin.

See also: "Copying and moving files" and "Undo".
