# Track changes and comments

Review changes without losing their context.

## How to use

Open **Review** and turn on **Track changes** when supported. Select an existing change to accept or reject it. **Accept all** and **Reject all** ask about the current listed changes. Select text and choose **New comment**, then use **Reply** or **Resolve** in the margin.

## Good to know

Imported authors and replies are preserved. Comments and tracked changes can contain personal information.

See also: "Editing documents" and "Hidden information and privacy".
