# Tags

Label files without changing their names.

## How to use

- Select files or folders, choose Add tags and apply named tags.
- Use Details or Manage tags to remove, rename, recolor or merge tags.

## Good to know

- Tags stay in this profile by default and use verified file identities.
- Copying or moving through the app can carry tags; some external moves cannot be followed.
- Embedded keywords are a separate explicit copy action.

See also: "Managing tags".
