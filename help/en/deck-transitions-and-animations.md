# Transitions and animations

Control supported slide changes and object effects. Select slides for Transitions or an object for Animations. Choose the effect, duration and start behavior, then preview it. Unsupported imported effects are listed as preserved only. They are not erased by an ordinary save. A static viewing fallback does not reproduce every animation.

## Good to know

- Changing one slide's transition or one object's animation never changes another slide or object.
- If the current engine cannot present an animation, the editor does not claim animation parity.
- Saving keeps unsupported imported effects in the file whenever safe preservation is available.

See also: "Editing presentations" and "File compatibility and limits".
