# Assistant capabilities

The assistant uses the same commands as the app.

## How to use it

Ask it to open or group tabs, find allowed files or prepare a new file, rename, copy, move, conversion, tag or privacy change. File changes always show a preview. Review the full source and destination list before **Apply**.

## Good to know

It cannot run system commands or delete permanently. Recycling needs two different human confirmations and a proven safe operation. Until that operation is available, assistant recycling is disabled. Unavailable packs or editing engines leave their actions unavailable.

See also: "The assistant" and "Assistant models and hardware".
