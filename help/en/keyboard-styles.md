# Keyboard shortcuts and styles

Choose a preset or save your own shortcuts.

## How to use

Open Settings > Keyboard shortcuts. Select Windows, Finder style, Commander style or Vim style. Capture a physical or character key, choose its context and resolve any conflict before saving.

## Good to know

Letter navigation works only outside text fields when enabled. Text editing and Windows-reserved shortcuts remain protected. Finder Enter renames in Explorer; Commander F5/F6 ask a copy or move destination. All operations retain normal confirmations and file safety.

See also: "Command palette" and "Customizing toolbars".
