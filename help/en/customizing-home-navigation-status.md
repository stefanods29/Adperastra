# Customizing Home, navigation and status

Keep useful sections and fields close.

## How to use

Use Edit Home to show, move and resize sections. In Navigation pane choose rows, custom folder labels and width. In Status bar choose fields for Explorer and each file type.

## Good to know

A display label does not rename a folder. Hidden sections stop optional loading. Important errors remain visible even with the status bar hidden.

See also: "Saved groups" and "Shareable setups".
