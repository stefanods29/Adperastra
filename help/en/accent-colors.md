# Accent colors

Choose readable colors for actions and file types.

## How to use

1. Open **Settings > Accent colors**.
2. Select a color from **Wallpaper colors**, or enter a color in the color box.
3. Enable **Always follow wallpaper** only if you want automatic local updates when the desktop background changes. This option is off by default.
4. Override individual file-type accents when needed: Explorer, Excel, Word, PDF, Image, PowerPoint and Group. A type with no choice keeps the theme's color.

## Good to know

- The app adjusts unsafe contrast or keeps a built-in color. It never silently exports a color that fails the normal-text or non-text contrast checks.
- Wallpaper colors stay on this PC and are not uploaded. The app reads only the current desktop background; it does not scan your pictures.
- The wallpaper palette can be unavailable on a locked-down or remote desktop. The picker then shows the built-in accent choices instead.
- File-type accents use the type's name, not a vendor logo or artwork.
