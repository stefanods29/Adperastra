# Browsing folders

The Explorer tab opens on the Home page. From there you can reach every folder on this PC.

## Moving around

- Double-click a folder to open it. Buttons at the top go **Back**, **Forward**, **Up** one level, and **Refresh**.
- Click a drive under **This PC** in the left pane to browse it. If a drive is asleep or disconnected, it says "still loading" or "not available" instead of freezing the app.
- The list shows Name, Date modified, Type, and Size. Click a column title to sort by it; click again to reverse the order. Names sort the natural way, so `file2` comes before `file10`.
- Type in the search box to filter the current folder by file name. This only filters the folder you are in; full search arrives in a later version.
- Hidden items are hidden, like in Windows. Turn on **View** > **Hidden items** to show them (they look faded).

## Good to know

- A cloud icon next to a file means it is stored online only. Adperastra will not download it in the background.
- A link icon means the item is a shortcut or link to somewhere else.
- Double-click a file to open it in its Windows default app. Built-in viewers arrive in a later version.
- To select, rename, or see details, read "Selecting files" and "The Details pane".
