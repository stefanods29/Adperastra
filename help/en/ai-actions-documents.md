# AI actions for documents

Select a supported file and choose AI actions. Choose Summarize, Create FAQ, Translate, Key points and action items or Ask about this file. Choose a target language for Translate or enter your question. Review the sources and the coverage notice beside the result. Save a copy creates a new text file; Discard closes the suggestion.

## How to use it

These suggestions do not edit the source. Check names, amounts, dates and source references. A partial or unreadable file is identified. Copy text uses Windows text recognition and needs no assistant pack. With an API backend, review the exact content and choose Send once before processing; opening a file does not approve sending it. Sensitive unlocked content stays local.
