# File details

The Details pane can show picture, music, video and document information.

## How to use

- Select one file.
- Open the **Details pane** to see its available information.
- In **Columns**, the preview column shows the same information.

## Good to know

- Some files do not contain every detail. Missing information is left out.
- Details load in the background and do not change the file.
- Online-only file contents are not downloaded.

See also: "Quick preview" and "Background work".
