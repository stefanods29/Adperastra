# Selecting files

Select files and folders to work with them: the command bar, the right-click menu, and the Details pane always act on what is selected.

## With the mouse

- Click an item to select it.
- **Ctrl**+click adds an item to the selection, or removes it.
- **Shift**+click selects everything between the last item you clicked and this one.
- Click an empty part of the list to clear the selection.
- Turn on **View** > **Item check boxes** to select with check boxes instead of holding Ctrl. The box in the column titles selects everything.

## With the keyboard

- The arrow keys, **Home**, **End**, **Page Up**, and **Page Down** move through the list. Hold **Shift** to extend the selection, or **Ctrl** to move without selecting, then **Ctrl+Space** to add or remove the item.
- **Ctrl+A** selects everything. **See more** (•••) also has **Select none** and **Invert selection**.
- Start typing a name to jump to it. Typing the same letter again moves to the next name that starts with it.
- **Enter** opens the selection. Folders open in the Explorer; files open in their Windows default app.

## Renaming

- Select one item and press **F2**, or click its name again after a moment (not a double-click). Only the name is selected, not the extension, so you can type right away.
- Press **Enter** or click elsewhere to save, or **Escape** to cancel.
- If Windows doesn't allow the name, or another item already has it, a message explains why and nothing is changed. Renaming never replaces another file.
- Renaming a Windows system item shows a warning first; press **Enter** again to rename it anyway, or **Escape** to cancel.
- Undo for renaming arrives in the next version.

## The status bar

The bottom bar shows how many items the folder has, how many are selected, and the total size of the selected files.
