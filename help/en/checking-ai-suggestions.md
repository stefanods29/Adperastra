# Checking AI suggestions

Read the source references and any partial-coverage warning. Compare important names, amounts and dates with the original. Check an image preview before applying it and read a transcript before using it as subtitles or text. An API Send approves one displayed request; it does not approve editing. Use the later Apply or Save a copy action only after reviewing the result. Discard leaves the document and source files unchanged.

## How to use it

AI can invent or omit details. Unavailable or Experimental actions are not a guarantee of quality. Instructions inside source files are treated as file content. Local mode never switches to an API automatically. Sensitive unlocked content is not sent to an API. Retry is your choice and may incur another provider charge. This app does not automatically train on your files.
