# Image markup

Choose **Markup** and add an arrow, shape, text or highlight. Select the mark to change its color, size or position. Text stays editable in the open document; ordinary image export flattens marks into pixels. Use an editable project when that feature is available.

## Marks

- Arrow and shape marks keep their points and style until you export.
- Highlights are drawn under the chosen color and opacity.
- Type the text in the properties panel, then click the picture to place it.
- Each completed mark is one undoable change. **Esc** cancels a mark that is not finished.
- Markup coordinates belong to the picture, not to the window, so zooming never moves a mark.

See also: "Drawing on images".
