# The right-click menu

Right-click an item, or an empty part of a folder, to see what you can do there. You can also press the **Menu** key on your keyboard.

## On a file or folder

- The buttons at the top: **Cut**, **Copy**, **Rename**, **Share**, **Delete**.
- **Open** opens the item. Files open in their Windows default app; folders open in the Explorer.
- **Open with…** lets you choose another app for a file.
- **Add to favorites** adds the item to Favorites on the Home page (or **Remove from favorites**).
- **Show in folder** (on the Home page) opens the folder that holds the item and selects it.
- **Copy as path** copies the full path, in quotes, to the clipboard.
- **Properties** opens the Windows Properties window.
- **Share** opens the Windows share sheet (files only).

## On empty space

**View**, **Sort by**, and **New** submenus, then **Paste**, **Open in Terminal** (Windows Terminal, or PowerShell if Windows Terminal isn't installed), and **Properties** for the folder.

## Show more options

**Show more options** (or **Shift+F10**) opens the classic Windows menu, with items added by other apps (for example 7-Zip, antivirus scanners, or Send to). It runs separately from Adperastra, so a slow or broken add-on can't freeze the app: if it takes more than a few seconds, Adperastra closes it and tells you.

Actions you choose in the classic menu are done by Windows, so Adperastra can't undo them.
