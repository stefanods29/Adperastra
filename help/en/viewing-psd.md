# Viewing PSD images

Inspect a saved composite and its layer names.

## How to use

- Open a PSD file.
- Use **Layers** to show or hide the layer list.
- Search inside the layer list to find a layer by name.
- Use **More options** to load the next page of a long layer list.

## Good to know

- The composite is the preview saved by the file's author. It is not rebuilt from the layers.
- Editing layers is not available here.
- Linked external content is not loaded.
- A file without a readable composite says so instead of showing a made-up picture.
- Very large files may need another app.

See also: "Viewing images" and "Quick preview".
