# Drawing on images

Switch to **Draw** and choose Brush, Pen, Highlighter, Erase, a shape, arrow or text. Set color and size in the properties panel. Each completed stroke is one undoable change. **Esc** cancels the unfinished gesture. Save a copy or export when finished.

## Tools

- **Brush** paints with the chosen softness, opacity and color.
- **Pen** uses a hard edge.
- **Highlighter** paints with low opacity so the picture stays visible.
- **Erase** removes pixels by lowering alpha.
- **Shapes** and **Arrow** add editable marks.
- **Text** places editable text; it becomes pixels only when you export an ordinary image.

## Keyboard and feedback

- The canvas is focusable while a drawing tool is active and gives the full text of the tool instructions.
- Every tool also has a button and a keyboard alternative in the properties panel.
- The status bar shows the current size and zoom.
