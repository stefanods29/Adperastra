# Tabs

Tabs work like in a web browser. Click a tab to switch to it.

With the keyboard: press **Tab** until the current tab has focus, then use the **Left** and **Right** arrow keys, **Home** or **End** to switch tabs. **Ctrl+W** closes the current tab.

The Explorer (Home) tab can never be closed. It has no close button, and **Ctrl+W** and middle-click do nothing on it. This keeps a place to browse your files always open.

Other tabs close with the **x** on the tab, with **Ctrl+W**, or with a middle-click on the tab.

Use the **+** button to open Help, Settings, and (for developers) the component gallery.
