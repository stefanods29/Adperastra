# Paste as file

When the clipboard holds text or an image instead of files, **Paste as file** saves it as a new file in the open folder.

## How to use it

- Copy text, or take a screenshot (for example with Win+Shift+S).
- In a folder, right-click empty space and choose **Paste as file**.
- The new file appears with its name selected, so you can rename it right away. It can be undone like any other action.

## What gets created

- **Text** becomes a text file. If the text looks like Markdown (headings, code blocks, links, or a Markdown table), it gets a `.md` ending; if it looks like a table with commas, semicolons, or tabs, it gets `.csv`; otherwise `.txt`.
- **Images and screenshots** become `.png` files, or `.jpg` if you chose JPG under **Settings** > **Pasted images**.
- Names follow Windows style, for example "Pasted image 2026-10-28 14-05.png". If the name is taken, a number is added.

If the clipboard holds files instead, **Paste as file** pastes them like a normal Paste.

See also: "Copying and moving files" and "Undo".
