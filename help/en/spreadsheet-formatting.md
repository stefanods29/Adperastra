# Formatting and conditional formatting

Format the selected cells.

## How to use

Use **Home** for font, alignment, number format and cell styles. Conditional formatting applies a chosen appearance when a typed rule matches. Review the target range and rule before confirming.

## Good to know

Formatting changes display, not the underlying value. Mixed controls mean selected cells have different settings.

See also: "Editing spreadsheets" and "Formulas".
