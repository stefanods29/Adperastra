# Converting documents

Select a document and open **Convert to…**.

## How to use it

- Choose a compatible format and inspect the preview and any layout or metadata warnings.
- Install the Office engine from App storage when requested.
- Choose a destination and **Convert** to create a new file.

## Good to know

- Macros and external links never run.
- Fonts and unsupported features can affect layout; compare important documents before using the result.
- Locked documents cannot use a conversion that needs a plaintext temporary file.

See also: "Viewing Office files" and "Removing hidden information".
