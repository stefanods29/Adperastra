# Formulas

Enter formulas using the app language.

## How to use

Start with an equals sign. Use **Insert function** to inspect available functions. Confirm the formula and review its result.

## Good to know

Display names and separators may differ by language; the stored formula keeps the same meaning. Unsupported functions can show saved values without recalculation. Imported formula-like clipboard text stays text.

See also: "Editing spreadsheets" and "Sorting and filtering".
