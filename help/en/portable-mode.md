# Portable mode

Keep the portable app's data beside the app.

## How to use

Unpack the portable ZIP into a writable folder and start Adperastra. Its data is stored in AdperastraData. Copy the entire portable folder when moving it to another drive, after closing the app.

## Good to know

A read-only folder needs another data location. Moving only the executable does not move settings, history or packs. Keep a backup of important files and version history.

See also: "Installing and updating".
