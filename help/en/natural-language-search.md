## How to use it
Choose **Natural language**, enter a request and review every filter chip, folder and resolved date. Edit the chips, then choose **Search**. Ambiguous or unsupported requests require clarification. Nothing runs before confirmation. API reasoning sends only the displayed content after a separate one-time Send confirmation.

See also: "Search filters" and "Indexing and privacy".
