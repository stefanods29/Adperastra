# Batch actions

Apply a compatible action to the selected files.

## How to use

Choose **Batch actions**, select a conversion preset or privacy cleaning, and review its options and warnings. Run the action and review the completed, skipped and failed items.

## Good to know

Each action keeps its normal safety choices. Retry acts only on unfinished items. Completed outputs remain if you cancel the rest.

See also: "Batch conversion and presets" and "Removing hidden information".
