# Shareable setups

Export selected appearance and layout data to another PC.

## How to use

Choose Export setup and select the parts. Personal paths are excluded unless explicitly selected. Import setup first shows contents and warnings. Choose the parts to apply and confirm.

## Good to know

Setups contain data, not executable code. Imports do not apply before confirmation. Original settings are retained for Undo or recovery if a change fails.

See also: "Theme editor" and "Profiles and portable data".
