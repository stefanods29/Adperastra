# Bulk rename

Preview new names for several files before changing anything.

## How to use

Select items and choose **Bulk rename**. Add the operations in the order you want. Review Current name and New name, exclude rows if needed, then choose **Rename**. Review any failures and use Undo to reverse the completed name changes.

## Good to know

Conflicting or invalid names cannot run. Originals are never replaced. If a rollback cannot restore a name, the report shows the actual recovery location; do not remove that item.

See also: "Selecting files" and "Batch actions".
