# Exporting documents to PDF

Create a separate PDF from the current document.

## How to use

Choose **File**, **Export to PDF**, review the page range and destination, and confirm. Export uses the current captured edits even if they are not saved to the original file.

## Good to know

Review compatibility warnings and inspect the exported PDF. The PDF is a separate file and does not replace the editable document.

See also: "Converting files" and "File compatibility and limits".
