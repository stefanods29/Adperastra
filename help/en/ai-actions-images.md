# AI actions for images

Open an image and choose AI actions. Choose Remove background, Blur background or Erase object. For Erase object, mark an area with the brush or enter a rectangle. Preview the result. Apply changes the open image once and can be undone; Save a copy creates a separate file. Describe image and Ask about this image show text suggestions. Enlarge with AI opens its own preview.

## How to use it

Image cleanup and enlargement run on this computer and need their optional packs. Text descriptions use your selected assistant backend. An API request needs a separate review and Send action; sensitive unlocked images are not sent. Check the result. Erase object may invent pixels inside the marked area. The original stays unchanged until an ordinary save.
