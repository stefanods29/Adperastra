# Mounting disk images

Browse supported disk images as read-only drives.

## How to use

Choose **Mount** for an ISO, VHD, VHDX or supported optical IMG. Review any Windows permission request. Open the resulting drive in This PC. Close its files and choose **Eject** when finished.

## Good to know

The app never mounts images writable. Raw IMG files are not generally supported. Images mounted by another program remain managed by Windows. Only the requested mount operation can ask for administrator permission.

See also: "This PC" and "Files in use".
