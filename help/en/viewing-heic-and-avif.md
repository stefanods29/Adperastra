# Viewing HEIC and AVIF images

View supported modern image formats.

## How to use

- Open the image normally. HEIC and HEIF use the Windows codec installed on this PC.
- AVIF keeps using the normal image viewer when the Windows web view supports it.
- If a compatible codec is missing, review the Windows codec instructions or choose your usual image app.
- Use the zoom and rotate controls like any other picture.

## Good to know

- Adperastra does not buy or install codecs automatically.
- Your image stays unchanged.
- The file type is checked from its content, not only from its name.
- A missing codec is shown as a clear notice, never as an empty picture.

See also: "Viewing images" and "Default apps".
