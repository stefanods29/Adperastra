# Recovering after a crash

Review saved recovery revisions after an unexpected exit.

## How to use

Choose a revision and select **Open recovered copy**. Review the copy before saving it to a location you choose. Use **Keep for later** to decide later, or **Discard recovery** to remove only that recovery record.

## Good to know

Original files are not replaced. Recovery is bounded and some large or locked documents cannot use the ordinary store. An opened recovered copy is a new file in app storage.

See also: "Sessions" and "Version history".
