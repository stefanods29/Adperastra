# Column sets

Assign useful metadata columns yourself.

## How to use

Enable manual column sets in **Settings > Views**. Create or edit a set and assign it to a folder, subtree or manually selected folder type. **Suggest column set** proposes a choice; **Apply** is still required.

## Good to know

Nothing is classified or changed automatically. Metadata loads in the background and online-only files are not downloaded.

See also: "Folder columns".
