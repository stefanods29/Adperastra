# Copying text from images and scans

Recognize text in a picture or scanned PDF page so you can select and copy it.

## How to use

- Open the image or PDF page.
- Choose **Copy all text** to recognize and copy its words.
- Choose **Search in this image** to find words on the page.
- Select a recognition language in **Settings > Background work** when needed.

## Good to know

Recognition happens on this computer. Its language must be installed in Windows. Results can contain mistakes, so check important text. Your file is never changed. Online-only files must be opened normally first.

See also: "Viewing PDFs" and "Background work".
