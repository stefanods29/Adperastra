# AI writing help in documents

Review a suggestion before changing your document.

## How to use it

Select a supported paragraph or insertion point and open **Review > AI writing help**. Choose **Rewrite**, **Shorten**, **Expand**, **Simplify**, **Fix grammar**, **Change tone**, **Translate**, **Draft a section** or **Continue writing**. For an image, choose **Write alt text**. Review the source, suggestion, changed facts and formatting preview. Edit or retry, then choose **Accept suggestion** when satisfied.

## Good to know

Nothing changes before acceptance. Current paragraph formatting and supported tracked changes are preserved; unsupported selections require narrowing. Check names, numbers, translations and generated facts. Undo reverses one accepted suggestion. Save still uses the normal safe document workflow.

An API backend sends only the content shown in its separate one-time Send review; accepting a suggestion is a later action.
