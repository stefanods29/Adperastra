# Batch conversion and presets

Reuse a conversion setup on several files.

## How to use it

- Select files and open **Convert to…**.
- Choose a compatible **Preset**, or adjust the options and choose **Save preset…**.
- Give it a name.
- Review the destination, file name pattern and any changes, then choose **Convert**.
- Review the per-file summary.

## Good to know

- Presets store options, not passwords or unsaved document contents.
- File names can use stem, ext, index and date fields.
- Not every format keeps all data or metadata.
- Originals are kept.
