# File compatibility and limits

Know which parts of a file can be edited safely.

## How to use

- Open **Compatibility and limits** before changing a complex file.
- Review items marked editable, preserved only, unsupported or blocked.
- Save a copy when changing formats and inspect the result.

## Good to know

A familiar extension does not guarantee full compatibility. Unsupported parts must survive an ordinary save, or saving that file is refused. A PDF or image export changes the format and may omit editable features. Original files remain available.

See also: "How Office editing works" and "Converting files".
