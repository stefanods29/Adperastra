# AI actions for audio and video

Open a supported audio or video file and choose Transcribe. Select English, Spanish or automatic language detection and, if needed, a shorter time range. Review the transcript. Select a time to seek without starting playback automatically. Summarize audio or video and Find moments use the reviewed transcript; enter a description for Find moments. Save a copy as plain text, SRT or VTT, or review subtitles in the media editor before applying them.

## How to use it

Speech recognition runs locally with Speech tools, independently of the assistant pack. It can mishear speech and does not identify speakers. The selected assistant backend processes summaries and searches; an API needs a separate content review and Send. File transcription supports at most one hour per request. Exporting a transcript never changes the media file.
