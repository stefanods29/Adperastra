# Removing hidden information

Inspect selected files and choose which hidden information to remove.

## How to use

Choose **Remove hidden information…**. Review the listed fields, select categories, and choose **Clean copy**. Confirm separately when removing forms, annotations or other content. Review the before-and-after result.

## Good to know

Nothing is removed by default. Originals are kept. The tool checks only the listed supported information, not every possible private fact or visible text. If removal cannot be verified, no cleaned file is published. Changing a signed PDF invalidates its existing signatures in the cleaned copy.

See also: "Privacy settings" and "Converting files".
