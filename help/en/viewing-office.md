# Viewing Office files

Open a Word document, spreadsheet or presentation in a file tab. Adperastra shows a quick or cached preview while preparing the accurate page view. Choose a sheet or slide in the navigation pane. Use Comments to read supported comments. Install the Office engine from App storage for accurate rendering; otherwise use Open in my chosen app. Views never change the source or run macros. Some features and fonts can look different; inspect important output.

See also: Presentation mode; Fonts and layout.
