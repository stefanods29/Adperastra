# Extraer tablas

Revisa una tabla detectada antes de crear una hoja.

## Cómo usarlo

Elige **Tablas a hoja de cálculo**, selecciona una tabla y corrige encabezados y celdas. Divide o combina columnas en la vista previa y exporta a XLSX o CSV.

## Conviene saber

El texto que parece una fórmula se conserva como texto. Una etiqueta ayuda a encontrar el original; no demuestra que el valor extraído sea correcto. Con un servicio de API, revisa el contenido mostrado del escaneo y confirma el envío una vez antes del procesamiento.

Consulta también: "Convertir escaneos en documentos" y "Convertir archivos".
