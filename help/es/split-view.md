# Vista dividida

Mantén dos vistas compatibles dentro de una pestaña.

## Cómo usar la vista dividida

- Elige **Abrir en vista dividida** o arrastra una pestaña compatible al destino dividido de otra.
- Elige **Lado a lado** o **Arriba y abajo**.
- Arrastra el divisor o enfócalo y usa las flechas.
- Elige **Intercambiar lados** para cambiar sus posiciones.
- Pulsa F6 para mover el foco entre los dos lados y la barra de herramientas.
- Activa **Sincronizar desplazamiento** cuando ambos lados lo admiten.

## Para tener en cuenta

- Los comandos y la cinta siguen al lado activo. **Cerrar este lado** mantiene abierta la otra vista.
- Ctrl+W cierra toda la pestaña tras comprobar cambios sin guardar.
- Las sesiones y los grupos guardados conservan las posiciones compatibles.
- Dos vistas de un mismo archivo editado comparten sus cambios: cerrar un lado no descarta el otro.
- Una vista dividida tiene dos lados. Para mostrar tres vistas, abre otra pestaña.

Consulta también: «Trabajar con pestañas» y «Copiar contenido entre pestañas».
