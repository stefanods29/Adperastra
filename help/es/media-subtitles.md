# Subtítulos

Elige un archivo compatible, revisa sus tiempos y selecciona **Desactivados**, mostrar o **Incrustar en el video**.

## Cómo usar

El texto incrustado forma parte de los píxeles exportados y no se puede desactivar allí. Nunca se ejecutan scripts ni vínculos externos de subtítulos. Guarda la receta para conservar la elección.

Consulta también: «Exportar contenido multimedia».
