# Cambiar idioma y tema

Abre la pestaña **Configuración** para cambiar estas opciones. Los cambios se aplican al instante. No necesitas reiniciar la aplicación.

**Idioma:** English o Espanol (Latinoamerica). Si falta una palabra en tu idioma, la aplicación la muestra en inglés.

**Tema:** Claro, Oscuro o Seguir Windows (usa tu configuración de Windows).

**Color de énfasis:** del diseño, de Windows o un color personalizado que elijas.

La configuración se guarda automáticamente en un archivo local en tu computadora.
