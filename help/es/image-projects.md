# Guardar proyectos de imagen

Usa **Guardar proyecto editable** para crear un archivo .adimage con capas, máscaras, ajustes, texto y datos de píxeles.

## Cómo usar

- Usa **Guardar proyecto editable** para crear un archivo .adimage con capas, máscaras, ajustes, texto y datos de píxeles.
- Ábrelo de nuevo para continuar; no depende de la ruta de la foto original.
- Exporta PNG, JPEG, WebP, TIFF o PDF para una copia aplanada.

## Para tener en cuenta

- Importar PSD muestra funciones no compatibles antes de crear una copia; no promete guardar y reabrir PSD editable sin cambios.
- Conserva el proyecto además de las imágenes exportadas.

Consulta también: «Capas de imagen».
