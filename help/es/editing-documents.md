# Editar documentos

Edita un documento compatible con controles locales.

## Cómo usar

Abre el archivo y elige **Habilitar edición** cuando aparezca. Escribe en el documento y usa **Inicio** para dar formato a la selección. Elige **Guardar** para conservar cambios en el mismo archivo compatible o **Guardar una copia** para crear otro archivo.

## Para tener en cuenta

El autoguardado comienza desactivado y solo se puede activar cuando se puede guardar de forma segura. Los archivos de internet comienzan en vista protegida. **Compatibilidad y límites** explica el contenido no compatible.

Consulta también: «Formato y estilos» y «Cambios sin guardar y recuperación».
