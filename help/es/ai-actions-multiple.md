# Acciones de IA para varios archivos

Selecciona dos documentos legibles y elige Comparar documentos. Revisa las referencias a ambos lados de cada diferencia. Para una carpeta, elige Resumir esta carpeta, revisa la lista y elige expresamente si quieres incluir contenido y subcarpetas. Confirma la lista antes de generar el resumen. Revisa los orígenes, los archivos omitidos y los avisos de lectura parcial o de solo nombres de archivo.

## Cómo usarlo

La aplicación solo lee el ámbito aprobado. Los nombres no demuestran qué contiene un archivo. El resumen admite hasta 100 archivos aprobados; si se supera el límite indicado, debes elegir un ámbito menor. La generación no renombra, mueve, elimina ni modifica esos archivos. Con una API, los nombres y fragmentos legibles necesitan otra revisión y la acción Enviar; un permiso anterior sobre una carpeta no autoriza su envío.
