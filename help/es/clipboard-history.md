# Historial del portapapeles

Reutiliza copias recientes sin cambiar sus archivos de origen.

## Cómo usar

Abre **Historial del portapapeles**, busca o elige un elemento y selecciona **Pegar elemento seleccionado**. Ancla un elemento para conservarlo cuando se llene el historial. Borra las referencias que no necesites.

## Para tener en cuenta

Por defecto el historial permanece en memoria. Capturar desde Windows y conservarlo cifrado son opciones independientes. Se omiten los elementos privados. Borrar el historial no elimina archivos ni vacía el portapapeles actual de Windows.

Consulta también: «Copiar contenido entre pestañas» y «La bandeja».
