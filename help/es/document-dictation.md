# Dictado

Inserta voz revisada mediante el paquete local.

## Cómo usar

Elige **Dictado**, permite el micrófono cuando quieras grabar y elige **Detener dictado**. Revisa la transcripción y aplícala a la posición capturada del documento.

## Para tener en cuenta

Cancelar no cambia el documento. El micrófono nunca inicia en segundo plano ni se envía a un proveedor de API.
