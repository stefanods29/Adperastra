# Firmar visualmente un PDF

Elige Firmar visualmente, dibuja o escribe una firma o selecciona una imagen y después colócala y ajusta su tamaño.

## Para tener en cuenta

Esta es una firma visual, no una firma digital certificada. Cambiar un PDF firmado digitalmente invalida su firma existente; usa Guardar una copia. Las imágenes de firma no se guardan para reutilizarlas de forma predeterminada.
