# Verificar copias

Comprueba los bytes copiados antes de publicar cada archivo.

## Cómo usar

Activa **Verificar archivos copiados** en las opciones de transferencia e inicia una copia. La aplicación lee la copia temporal completa y compara su hash con el origen.

## Para tener en cuenta

La verificación necesita tiempo adicional de lectura. Si no coincide, se conserva el original y no se crea ese resultado. Los movimientos entre unidades siempre comprueban el tamaño de la copia antes de quitar el origen.

Consulta también: «Copias y conflictos» y «La cola de tareas».
