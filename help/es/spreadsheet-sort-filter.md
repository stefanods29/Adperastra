# Ordenar y filtrar

Organiza filas sin mezclar sus datos.

## Cómo usar

Selecciona el rectángulo completo y elige **Ordenar** o **Filtrar**. Revisa si la primera fila es un encabezado.

## Para tener en cuenta

Ordenar mueve filas completas dentro del intervalo; Filtrar oculta las que no coinciden. Borrar filtro vuelve a mostrarlas. Ninguna acción actualiza datos externos.

Consulta también: «Editar hojas de cálculo» y «Fórmulas».
