# Copias y conflictos

Copia o mueve archivos manteniendo el control de las tareas largas.

## Cómo usar

Inicia una copia o movimiento y abre su ventana. Usa **Pausar**, **Reanudar**, **Omitir archivo** o **Cancelar**. Si ya se usa un nombre, compara ambos elementos y elige **Omitir**, **Conservar ambos** o **Combinar carpetas** cuando se ofrezca.

## Para tener en cuenta

Los archivos terminados permanecen si cancelas. Reemplazar no está disponible hasta poder proteger el archivo existente exacto. Deshacer puede rechazarse si un elemento cambió fuera de la aplicación; se conservan los archivos.

Consulta también: «Archivos en uso» y «La cola de tareas».
