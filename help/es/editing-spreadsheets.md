# Editar hojas de cálculo

Edita un libro compatible de forma local.

## Cómo usar

Abre el archivo, habilita la edición cuando aparezca y selecciona una celda. Escribe un valor o usa la barra de fórmulas. Intro confirma y Escape cancela la edición actual. Las pestañas permiten agregar, renombrar o reordenar hojas. **Guardar** conserva los cambios compatibles; **Guardar una copia** crea otro archivo.

## Para tener en cuenta

No se ejecutan conexiones externas ni macros.

Consulta también: «Fórmulas» y «Compatibilidad y límites de archivos».
