# Buscar duplicados

Revisa archivos con bytes idénticos verificados.

## Cómo usar

Elige carpetas y Buscar duplicados. Compara grupos verificados, selecciona copias a conservar y revisa las propuestas para la Papelera. Nada se elige para quitar automáticamente.

## Para tener en cuenta

La apariencia similar no basta. Los enlaces al mismo archivo son una copia física. Debe quedar una copia verificada. La limpieza no está disponible si el envío no se puede ligar de forma segura a los objetos revisados; abrir y revisar siguen funcionando.

Consulta también: «Vista de almacenamiento».
