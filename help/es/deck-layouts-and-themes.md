# Disposiciones y temas

Mantén diapositivas uniformes sin descartar contenido. Selecciona diapositivas y elige Disposición para un patrón de posiciones o Tema para colores, fuentes y disposiciones. Revisa el contenido que no cabe antes de confirmar. Los patrones definen valores reutilizables. Se conservan el formato manual y los objetos sin marcadores coincidentes. La biblioteca de estilos ofrece opciones manuales adicionales cuando está disponible.

## Para tener en cuenta

- Una disposición nunca elimina un objeto para que quepa. Revisa el contenido sin coincidencia o que no cabe antes de confirmar.
- Cambiar el tema es un solo paso de Deshacer y conserva el formato manual.
- Los datos de patrón importados que el motor no puede editar se conservan como contenido opaco.

Consulta también: «Editar presentaciones» y «La biblioteca de estilos».
