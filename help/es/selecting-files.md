# Seleccionar archivos

Selecciona archivos y carpetas para trabajar con ellos: la barra de comandos, el menú del clic derecho y el panel de detalles siempre actúan sobre lo seleccionado.

## Con el mouse

- Haz clic en un elemento para seleccionarlo.
- **Ctrl**+clic agrega un elemento a la selección o lo quita.
- **Mayús**+clic selecciona todo lo que hay entre el último elemento en que hiciste clic y este.
- Haz clic en una parte vacía de la lista para quitar la selección.
- Activa **Ver** > **Casillas de elementos** para seleccionar con casillas en lugar de mantener Ctrl. La casilla de los títulos de columna selecciona todo.

## Con el teclado

- Las flechas, **Inicio**, **Fin**, **Re Pág** y **Av Pág** recorren la lista. Mantén **Mayús** para ampliar la selección, o **Ctrl** para moverte sin seleccionar, y luego **Ctrl+Espacio** para agregar o quitar el elemento.
- **Ctrl+A** selecciona todo. **Ver más** (•••) también tiene **No seleccionar nada** e **Invertir selección**.
- Empieza a escribir un nombre para saltar a él. Si vuelves a escribir la misma letra, pasas al siguiente nombre que empieza con ella.
- **Entrar** abre la selección. Las carpetas se abren en el Explorador; los archivos, en su app predeterminada de Windows.

## Cambiar el nombre

- Selecciona un elemento y presiona **F2**, o vuelve a hacer clic en su nombre después de un momento (sin doble clic). Solo queda seleccionado el nombre, no la extensión, así que puedes escribir de inmediato.
- Presiona **Entrar** o haz clic en otro lugar para guardar, o **Esc** para cancelar.
- Si Windows no permite el nombre, o ya hay otro elemento con ese nombre, un mensaje explica por qué y no se cambia nada. Cambiar un nombre nunca reemplaza otro archivo.
- Al cambiar el nombre de un elemento del sistema de Windows aparece primero una advertencia; presiona **Entrar** otra vez para cambiarlo de todos modos, o **Esc** para cancelar.
- La opción de deshacer un cambio de nombre llega en la próxima versión.

## La barra de estado

La barra inferior muestra cuántos elementos tiene la carpeta, cuántos están seleccionados y el tamaño total de los archivos seleccionados.
