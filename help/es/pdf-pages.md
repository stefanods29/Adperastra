# Reorganizar páginas PDF

Abre Herramientas de páginas. Selecciona miniaturas para girar o eliminar páginas, arrastra para reordenar o elige Insertar páginas o Unir PDF. Dividir crea archivos nuevos para los intervalos elegidos.

## Para tener en cuenta

El PDF debe conservar al menos una página. Revisa el orden y deshaz los errores antes de guardar. Las estructuras entre páginas no compatibles pueden exigir rechazar un cambio para no perder datos.
