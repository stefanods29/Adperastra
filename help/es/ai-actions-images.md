# Acciones de IA para imágenes

Abre una imagen y elige Acciones de IA. Elige Quitar fondo, Desenfocar fondo o Borrar objeto. Para Borrar objeto, marca un área con el pincel o introduce un rectángulo. Revisa el resultado. Aplicar cambia una vez la imagen abierta y se puede deshacer; Guardar una copia crea otro archivo. Describir imagen y Preguntar sobre esta imagen muestran sugerencias de texto. Ampliar con IA abre su propia vista previa.

## Cómo usarlo

La limpieza y ampliación de imágenes se procesan en este equipo y necesitan sus paquetes opcionales. Las descripciones usan el servicio elegido para el asistente. Una solicitud de API necesita una revisión aparte y la acción Enviar; no se envían imágenes sensibles desbloqueadas. Revisa el resultado. Borrar objeto puede inventar píxeles dentro del área marcada. El original se conserva hasta que lo guardes de la forma habitual.
