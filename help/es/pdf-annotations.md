# Resaltar y dibujar en PDF

Habilita la edición, elige Resaltar, Dibujar o Cuadro de texto y coloca la marca en una página.

## Cómo usar

Selecciona una marca para cambiar color, tamaño o texto. Deshacer y Rehacer recorren el historial. Guarda una copia para conservar el original.

## Para tener en cuenta

Las marcas se guardan como anotaciones PDF estándar con su apariencia. Algunas estructuras no compatibles pueden impedir guardar de forma segura.
