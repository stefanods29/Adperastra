# Herramientas de pintura

Elige **Pincel**, **Borrar**, **Rellenar**, **Degradado** o **Tampón de clonar** para pintar directamente sobre la imagen.

## Cómo usar

- Elige **Pincel**, **Borrar**, **Rellenar**, **Degradado** o **Tampón de clonar**.
- Configura tamaño, dureza, opacidad, flujo y espaciado; un lápiz puede controlar el tamaño con presión.
- Alt-clic fija el origen de clonado.

## Para tener en cuenta

- Cada pincelada terminada es un cambio que se puede deshacer.
- Las máscaras de selección limitan los píxeles afectados.
- Son herramientas deterministas sin modelos de IA.

Consulta también: «Selecciones de imagen».
