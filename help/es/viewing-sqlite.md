# Ver bases de datos SQLite

Revisa tablas sin cambiar una base de datos.

## Cómo usar

Abre un archivo SQLite, elige una tabla y revisa u ordena sus filas. Este visor no ejecuta SQL arbitrario ni edita datos.

## Para tener en cuenta

Es posible que debas cerrar la base en otra aplicación o abrir una copia segura.

Consulta también: «Ver tablas» y «Abrir archivos».
