# Expresiones regulares

Busca nombres o contenido indexado con un patrón limitado.

## Cómo usar

- Selecciona **Expresión regular** y elige nombres o contenido.
- Escribe una expresión compatible.
- **Cancelar** detiene un examen largo.

## Para tener en cuenta

- No se admiten referencias hacia atrás ni anticipaciones.
- Una expresión no ejecuta programas ni modifica archivos.

Consulta también: «Buscar».
