# Usar la ayuda

La ayuda se abre en una pestaña, como cualquier otra página. Funciona sin conexión y en tu idioma.

Usa el cuadro de búsqueda para encontrar una página por palabras de su título o texto.

Presiona **F1** para abrir la página de ayuda de lo que estás haciendo. El botón **?** en paneles y diálogos también abre la página correspondiente.

Las páginas de ayuda son archivos pequeños. Esto facilita agregar nuevas traducciones más adelante.
