# Accesibilidad

Combina las opciones que faciliten el uso de la aplicación.

## Cómo usar

Abre Configuración > Accesibilidad y elige Visión, Audición, Motricidad y destreza, Comprensión y aprendizaje o Movimiento y comodidad. Se respetan automáticamente el contraste alto y el movimiento reducido de Windows.

## Para tener en cuenta

Las acciones principales tienen rutas de teclado y nombres visibles. Las preferencias visuales no modifican archivos.

Consulta también: «Accesibilidad visual» y «Accesibilidad motriz».
