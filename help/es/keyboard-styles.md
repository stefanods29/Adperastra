# Atajos y estilos de teclado

Elige un ajuste o guarda tus propios atajos.

## Cómo usar

Abre Configuración > Atajos de teclado. Selecciona Windows, estilo Finder, Commander o Vim. Captura una tecla física o un carácter, elige el contexto y resuelve los conflictos antes de guardar.

## Para tener en cuenta

La navegación con letras funciona solo fuera de campos de texto cuando está activada. Se protegen la edición de texto y los atajos reservados por Windows. Intro cambia nombres en Explorer con el estilo Finder; F5/F6 piden un destino con Commander. Todas las operaciones conservan sus confirmaciones y seguridad.

Consulta también: «Paleta de comandos» y «Personalizar barras de herramientas».
