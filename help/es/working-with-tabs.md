# Trabajar con pestañas

Mantén abiertas varias carpetas y archivos mientras trabajas.

## Cómo usar las pestañas

- Usa **Abrir en una pestaña nueva** para una carpeta o elige **Nueva pestaña de carpeta** en el menú del signo más.
- Haz clic derecho en una pestaña para anclarla, duplicarla o cerrarla.
- Usa Ctrl+Tab para cambiar y Ctrl+Mayús+T para volver a abrir una pestaña cerrada.
- Usa Ctrl+1 a Ctrl+8 para ir a una pestaña por su posición y Ctrl+9 para ir a la última.
- Haz clic con el botón central en una pestaña para cerrarla.

## Para tener en cuenta

- La pestaña permanente del Explorador no se puede cerrar.
- Las pestañas de carpetas conservan vistas independientes.
- Dos vistas de un documento editado comparten sus cambios; cerrar una no descarta la otra.
- Puedes abrir hasta 200 pestañas.

Consulta también: «Sesiones» y «Abrir archivos».
