# Informar un problema

Prepara un diagnóstico local que puedes revisar antes de compartir.

## Cómo usar

Abre **Informar un problema**. Revisa los archivos incluidos, edita o excluye texto y mantén ocultas las rutas y los nombres. Elige **Guardar ZIP de diagnóstico…**. Si quieres informar el error, elige **Abrir página de incidencias** y adjunta el ZIP tú mismo.

## Para tener en cuenta

No se sube nada automáticamente. El ocultamiento puede omitir información; revísala. Los volcados están excluidos por defecto y pueden contener datos privados.

Consulta también: «Modo seguro» y «Recuperar después de un cierre inesperado».
