# Configuraciones compartibles

Exporta partes de apariencia y distribución a otra PC.

## Cómo usar

Elige Exportar configuración y selecciona las partes. Las rutas personales se excluyen salvo selección explícita. Importar configuración muestra primero contenido y avisos. Elige las partes y confirma.

## Para tener en cuenta

Contienen datos, no código ejecutable. La importación no aplica nada antes de confirmar. Se conserva la configuración original para Deshacer o recuperar un cambio fallido.

Consulta también: «Editor de temas» y «Perfiles y datos portátiles».
