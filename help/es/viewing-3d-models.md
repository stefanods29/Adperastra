# Ver modelos 3D

Revisa un modelo desde distintos ángulos sin cambiarlo.

## Cómo usar

- Abre un modelo compatible: STL, OBJ, glTF, GLB o 3MF.
- Arrastra con el mouse para girar alrededor del modelo y usa la rueda del mouse para acercar o alejar.
- Con el lienzo del modelo enfocado, usa las flechas para girar la vista y **+** o **-** para el zoom.
- Elige **Ajustar modelo** para volver a la vista inicial.
- Elige **Malla de alambre** para revisar la estructura.
- Elige **Medir** y luego selecciona dos puntos del modelo para ver su distancia.
- Usa **Unidades** para elegir las unidades del archivo, milímetros, centímetros o metros.

## Para tener en cuenta

- Las unidades del archivo no siempre son unidades físicas. Un modelo sin unidad declarada se muestra como **Unidades del archivo**.
- No se cargan recursos remotos o inseguros, y los archivos de textura fuera de la carpeta del modelo se rechazan.
- El modelo nunca cambia.
- Pueden faltar algunos recursos de un modelo dañado o poco común; la vista lo indica en lugar de aparentar que el modelo está completo.
- Los modelos muy grandes o comprimidos pueden necesitar otra aplicación.

Consulta también: «Vista previa rápida» y «Abrir archivos».
