# Integración con el Explorador de Windows

Agrega comandos opcionales de Adperastra al Explorador de Windows. El menú clásico y el menú principal de Windows 11 son opciones separadas.

## Cómo usar

- Abre **Configuración > Integración con Windows** para agregar comandos opcionales.
- **Agregar comandos en Mostrar más opciones** usa el menú clásico de Windows.
- Usa **Elegir aplicaciones predeterminadas…** para abrir Configuración de Windows; tú haces la elección allí.

## Para tener en cuenta

- El menú principal de Windows 11 necesita una identidad de paquete y una distribución de confianza aprobadas, así que aparece por separado y puede no estar disponible.
- **Convertir en…** abre el diálogo de revisión de Adperastra; no cambia archivos inmediatamente.
- Desactiva la integración aquí para quitar solo sus entradas. Las entradas que otro programa cambió se conservan.

Consulta también: «Asociaciones de archivos».
