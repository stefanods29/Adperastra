# Colores de énfasis

Elige colores legibles para acciones y tipos de archivo.

## Cómo usar

1. Abre **Configuración > Colores de énfasis**.
2. Selecciona un color de **Colores del fondo de pantalla** o indica uno en el cuadro de color.
3. Activa **Seguir siempre el fondo de pantalla** solo si quieres actualizaciones locales automáticas cuando cambie el fondo del escritorio. Esta opción está desactivada de forma predeterminada.
4. Cambia colores de tipos de archivo cuando lo necesites: Explorador, Excel, Word, PDF, Imagen, PowerPoint y Grupo. Un tipo sin elección conserva el color del tema.

## Para tener en cuenta

- La aplicación ajusta el contraste insuficiente o conserva un color predeterminado. Nunca exporta en silencio un color que no cumpla las comprobaciones de contraste para texto normal o elementos no textuales.
- Los colores permanecen en esta PC y no se envían. La aplicación lee solo el fondo de escritorio actual; no examina tus imágenes.
- La paleta del fondo puede no estar disponible en un escritorio remoto o restringido. En ese caso se muestran los colores de énfasis predeterminados.
- Los colores de tipo de archivo usan el nombre del tipo, no un logotipo ni material de la marca.
