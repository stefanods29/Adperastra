# Grupos de pestañas

Mantén juntas las pestañas relacionadas sin mover sus archivos.

## Cómo usar

- Haz clic derecho en una pestaña y elige **Agregar pestaña a un grupo > Nuevo grupo**. Dale un nombre y un color.
- Usa su etiqueta para contraerlo o expandirlo. Haz clic derecho en la etiqueta para cambiar el nombre o color, desagrupar o cerrar el grupo.
- Arrastra la etiqueta para mover todo el grupo. Quitar una pestaña de un grupo la coloca justo después del grupo.

## Para tener en cuenta

- Desagrupar mantiene abiertas las pestañas. Cerrar un grupo comprueba los cambios sin guardar.
- Las pestañas ancladas y la pestaña permanente del Explorador quedan fuera de los grupos.
- El color nunca es la única señal: cada grupo también tiene un nombre y un número de pestañas.

Consulta también: «Grupos guardados» y «Trabajar con pestañas».
