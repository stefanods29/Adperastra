# Capas de ajuste y filtros

Agrega una capa de ajuste para curvas, niveles, color, desenfoque, nitidez o reducción de ruido.

## Cómo usar

- Agrega una capa de ajuste para curvas, niveles, color, desenfoque, nitidez o reducción de ruido.
- Cambia valores, opacidad o máscara sin reescribir los píxeles originales.
- Reordénala para cambiar las capas afectadas.
- Desactívala para comparar y usa Deshacer para revertir.

## Para tener en cuenta

- La exportación usa los mismos cálculos que la vista previa.

Consulta también: «Capas de imagen».
