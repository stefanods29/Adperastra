# Editar presentaciones

Edita una presentación compatible de forma local. Abre el archivo y habilita la edición cuando aparezca. Selecciona una diapositiva en el panel izquierdo y usa Inicio o Insertar para editar texto y objetos. Usa Notas debajo para las notas del orador. Guardar conserva cambios compatibles; Guardar una copia crea otro archivo. El contenido importado no compatible se conserva cuando se puede guardar de forma segura.

## Para tener en cuenta

- Los efectos y objetos importados no compatibles se conservan; guardar normalmente no los borra.
- Si no se puede conservar de forma segura, se impide guardar ese archivo. Usa una copia compatible o ábrelo en tu aplicación elegida.
- El contenido de carpetas bloqueadas permanece en memoria; nunca se escribe una copia de recuperación sin cifrar.

Consulta también: «Disposiciones y temas» y «Presentar».
