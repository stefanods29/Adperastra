# Ver registros

Lee registros grandes por páginas.

## Cómo usar

Abre un registro y usa Buscar o Seguir líneas nuevas. Las etiquetas de nivel distinguen los mensajes sin depender solo del color.

## Para tener en cuenta

Las líneas largas pueden acortarse con un aviso. El archivo nunca cambia.

Consulta también: «Ver texto» y «Vista previa rápida».
