# Modo de presentación

Abre una presentación y elige Presentar, o pulsa F5 con el visor activo. Usa las flechas o Re Pág/Av Pág para cambiar de diapositiva y Esc para volver. La ventana del público muestra solo diapositivas; las notas y comentarios quedan fuera. La vista del moderador y la edición se agregan por separado.
