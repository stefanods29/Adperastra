# Ver imágenes PSD

Revisa la imagen compuesta guardada y los nombres de las capas.

## Cómo usar

- Abre un archivo PSD.
- Usa **Capas** para mostrar u ocultar la lista de capas.
- Busca dentro de la lista de capas para encontrar una capa por su nombre.
- Usa **Más opciones** para cargar la siguiente página de una lista de capas larga.

## Para tener en cuenta

- La imagen compuesta es la vista previa guardada por quien creó el archivo. No se reconstruye a partir de las capas.
- Aquí no puedes editar capas.
- No se carga contenido externo vinculado.
- Si un archivo no tiene una imagen compuesta que se pueda leer, se indica en lugar de mostrar una imagen inventada.
- Los archivos muy grandes pueden necesitar otra aplicación.

Consulta también: «Ver imágenes» y «Vista previa rápida».
