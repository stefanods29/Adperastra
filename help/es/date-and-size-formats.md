# Formatos de fecha y tamaño

Muestra fechas, números y nombres de forma coherente.

## Cómo usar

Abre **Configuración > Formatos de fecha y tamaño**. Elige región, estilo de fecha, hora y tamaños decimales o binarios. Un patrón personalizado acepta solo los campos indicados. Elige recorte central o final para nombres largos.

## Para tener en cuenta

Estas opciones no cambian los nombres ni valores de orden. La configuración existente conserva sus etiquetas de tamaño hasta que las cambies.

Consulta también: «Opciones de pestañas».
