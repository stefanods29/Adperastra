# Modelos y hardware del asistente

Elige un modelo local o la API de Meta.

## Cómo usarlo

Los modelos locales son paquetes opcionales de **Almacenamiento de la aplicación**. Los modelos pequeños necesitan menos memoria; el tamaño recomendado es un punto de partida. Para usar Meta, elige **Clave de API**, selecciona **Introducir o cambiar clave…**, después **Probar conexión** y un modelo compatible. Revisa los posibles cargos del proveedor. Para usar un modelo que ya funciona localmente, elige **Modelo que ya ejecuto** y su dirección local y puerto.

## Conviene saber

El procesamiento local incluido permanece en este equipo. Un servidor local separado puede reenviar contenido. El modo de API usa la red solo en solicitudes que apruebas. Los errores detienen la solicitud; tú decides si elegir IA local o reintentar. Reintentar puede generar cargos. Nunca se descarga un modelo ni se compra una cuenta automáticamente.

Consulta también: "Paquetes de IA y hardware" y "Preferencias y privacidad del asistente".
