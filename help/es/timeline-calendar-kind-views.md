# Línea de tiempo, Calendario y Por tipo

Explora archivos indexados por fecha o tipo.

## Cómo usar

- Abre una vista en navegación, elige carpetas, fecha y filtros y abre archivos normalmente.
- El calendario muestra cantidades; la línea de tiempo agrupa desde días hasta años.

## Para tener en cuenta

- Las fechas ausentes aparecen Sin fecha.
- Las vistas no mueven archivos.

Consulta también: «Indexación y privacidad».
