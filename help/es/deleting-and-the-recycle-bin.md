# Eliminar y la Papelera de reciclaje

## Eliminar

Selecciona los elementos y pulsa **Supr** (o el botón Eliminar de la barra de comandos). Los elementos van a la Papelera de reciclaje de Windows, así que puedes recuperarlos:

- Elige **Deshacer** en el mensaje que aparece, o pulsa Ctrl+Z, para devolver todo a su sitio.
- O abre la Papelera de reciclaje en el Explorador de Windows y restaura los elementos ahí.

Eliminar nunca sobrescribe nada: si mientras tanto un elemento nuevo ocupó el nombre del eliminado, la restauración se omite y el elemento eliminado se queda en la Papelera.

## Eliminar permanentemente

**Eliminar permanentemente** (Mayús+Supr) se salta la Papelera. Como no se puede deshacer, siempre se te pregunta antes, y el mensaje dice claramente que no se podrá deshacer.

## La Papelera es de Windows

Adperastra usa la misma Papelera de reciclaje de Windows que el Explorador, con los mismos límites de tamaño que Windows define en cada unidad. Cuando la Papelera se llena, Windows elimina por sí mismo los elementos más antiguos.

Consulta también: «Deshacer» y «Copiar y mover archivos».
