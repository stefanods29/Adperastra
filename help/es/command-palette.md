# Paleta de comandos

Busca comandos, pestañas y ubicaciones desde un solo campo.

## Cómo usar

Pulsa Ctrl+K y escribe en el idioma de la aplicación o en inglés. Usa las flechas e Intro para elegir un resultado. Pulsa Esc para volver.

## Para tener en cuenta

Los comandos no disponibles muestran un motivo y no se ejecutan. Abrir una ubicación sigue las reglas normales de apertura. Las acciones recientes permanecen en esta PC.

Consulta también: «Atajos y estilos de teclado» y «Grupos guardados».
