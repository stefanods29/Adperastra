# Ayuda de escritura con IA en documentos

Revisa una sugerencia antes de cambiar el documento.

## Cómo usarlo

Selecciona un párrafo o punto de inserción compatible y abre **Revisar > Ayuda de escritura con IA**. Elige **Reescribir**, **Acortar**, **Ampliar**, **Simplificar**, **Corregir gramática**, **Cambiar tono**, **Traducir**, **Redactar una sección** o **Continuar escribiendo**. Para una imagen, elige **Escribir texto alternativo**. Revisa el origen, la sugerencia, los datos cambiados y el formato. Edita o reintenta y elige **Aceptar sugerencia** cuando estés conforme.

## Conviene saber

Nada cambia antes de aceptar. Se conservan el formato del párrafo y los cambios compatibles; reduce las selecciones no compatibles. Comprueba nombres, números, traducciones y datos generados. Deshacer revierte una sugerencia aceptada. Guardar sigue el procedimiento seguro normal.

Un servicio de API envía solo el contenido mostrado en su revisión separada de envío de una sola vez; aceptar una sugerencia es una acción posterior.

Consulta también: "Niveles de calidad de IA" y "Control de cambios y comentarios".
