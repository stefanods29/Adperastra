# Detalles de archivos

El Panel de detalles puede mostrar información de imágenes, música, videos y documentos.

## Cómo usar

- Selecciona un archivo.
- Abre el **Panel de detalles** para ver la información disponible.
- En **Columnas**, la columna de vista previa muestra la misma información.

## Para tener en cuenta

- Algunos archivos no contienen todos los detalles. La información que falta no se muestra.
- Los detalles cargan en segundo plano y no cambian el archivo.
- No se descarga el contenido de archivos solo en línea.

Consulta también: «Vista previa rápida» y «Trabajo en segundo plano».
