# Acciones de IA para documentos

Selecciona un archivo compatible y elige Acciones de IA. Elige Resumir, Crear preguntas frecuentes, Traducir, Puntos clave y tareas o Preguntar sobre este archivo. Para Traducir, elige el idioma de destino; para una pregunta, escribe lo que buscas. Revisa los orígenes y el aviso de cobertura junto al resultado. Guardar una copia crea otro archivo de texto; Descartar cierra la sugerencia.

## Cómo usarlo

Estas sugerencias no modifican el origen. Comprueba nombres, importes, fechas y referencias. Se indica cuando un archivo solo se ha leído en parte o no se puede leer. Copiar texto usa el reconocimiento de texto de Windows y no necesita el paquete del asistente. Con una API, revisa el contenido exacto y elige Enviar una vez antes del procesamiento; abrir un archivo no autoriza su envío. El contenido sensible desbloqueado permanece en este equipo.
