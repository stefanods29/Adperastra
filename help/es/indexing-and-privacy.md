# Indexación y privacidad

Controla qué nombres y texto locales se guardan.

## Cómo usar

- Agrega solo carpetas que quieras indexar.
- Activa contenido y OCR por separado.
- Pausa, reconstruye o quita una carpeta en **Configuración**.

## Para tener en cuenta

- El índice permanece en este perfil con un límite.
- Se excluye contenido sensible desbloqueado.
- Quitar datos del índice no elimina archivos.
- El permiso NTFS opcional no se necesita para explorar normalmente.

Consulta también: «Almacenamiento de la aplicación».
