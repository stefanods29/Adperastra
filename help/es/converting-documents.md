# Convertir documentos

Selecciona un documento y abre **Convertir en…**.

## Cómo usarla

- Elige un formato compatible y revisa la vista previa y los avisos de diseño o metadatos.
- Instala el motor de Office desde Almacenamiento de la aplicación cuando se solicite.
- Elige un destino y **Convertir** para crear un archivo nuevo.

## Para tener en cuenta

- Nunca se ejecutan macros ni vínculos externos.
- Las fuentes y funciones no compatibles pueden afectar el diseño; compara los documentos importantes antes de usar el resultado.
- Los documentos bloqueados no pueden usar una conversión que necesite un archivo temporal sin cifrar.

Consulta también: «Ver archivos de Office» y «Quitar información oculta».
