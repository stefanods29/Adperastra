# Buscar en lenguaje natural
Describe las propiedades de los archivos que buscas.

## Cómo usarlo
Elige **Lenguaje natural**, escribe la solicitud y revisa cada filtro, carpeta y fecha resuelta. Edita los filtros y elige **Buscar**. Las solicitudes ambiguas o no compatibles requieren aclaración. Nada se ejecuta antes de confirmar. El razonamiento por API envía solo el contenido mostrado tras una confirmación de envío separada y de una sola vez.

Consulta también: «Filtros de búsqueda» e «Indexación y privacidad».
