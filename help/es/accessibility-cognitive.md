# Accesibilidad cognitiva

Reduce la complejidad visual y mantén cerca las explicaciones.

## Cómo usar

Activa Modo sencillo, confirmaciones opcionales y avisos persistentes. Explicar esto abre la ayuda correspondiente.

## Para tener en cuenta

El modo sencillo oculta controles avanzados sin eliminar funciones ni archivos. El progreso incluye palabras y Cancelar cuando corresponde.
