# La biblioteca de estilos

Elige un estilo manual para tu presentación.

## Cómo usar

Abre **Diseño > Biblioteca de estilos**. Elige **Toda la presentación** o **Diapositivas seleccionadas**. Revisa colores, fuentes, disposiciones y densidad de un estilo y elige **Aplicar estilo**. Revisa las fuentes que faltan o el contenido que no cabe antes de confirmar. Usa Deshacer para volver al estilo anterior.

## Para tener en cuenta

Los estilos no escriben, acortan ni eliminan tu texto. Se conservan el formato manual y los objetos sin coincidencia. Las pautas son solo sugerencias. La generación opcional con IA usa estos mismos estilos tras una revisión separada.

Consulta también: «Disposiciones y temas» y «Agregar mis propios estilos».
