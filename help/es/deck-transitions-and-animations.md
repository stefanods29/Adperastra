# Transiciones y animaciones

Controla cambios de diapositiva y efectos de objetos compatibles. Selecciona diapositivas para Transiciones o un objeto para Animaciones. Elige efecto, duración e inicio y revisa la vista previa. Los efectos importados no compatibles aparecen como solo conservados. Guardar normalmente no los borra. Un visor estático no reproduce todas las animaciones.

## Para tener en cuenta

- Cambiar la transición de una diapositiva o la animación de un objeto no modifica otra diapositiva ni otro objeto.
- Si el motor actual no puede presentar una animación, el editor no promete que se vea igual.
- Guardar conserva los efectos importados no compatibles siempre que se pueda preservar de forma segura.

Consulta también: «Editar presentaciones» y «Compatibilidad y límites de archivos».
