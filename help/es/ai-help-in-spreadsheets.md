# Ayuda de hojas de cálculo con IA

Revisa fórmulas calculadas y cambios tipados antes de editar un libro.

## Cómo usarlo

Selecciona un intervalo y elige una acción de IA. **Escribir una fórmula que…** propone una fórmula, comprueba sus funciones y referencias compatibles y la calcula en una copia separada antes de insertarla. Revisa la forma canónica, la forma en tu idioma y el resultado real. **Explicar esta fórmula** y **Describir esta tabla** generan texto de solo lectura. **Limpiar estos datos** muestra cada cambio de celda; elige reglas explícitas de fechas y números. **Sugerir un gráfico** representa un gráfico real con las celdas seleccionadas. Acepta solo los cambios que revisaste.

## Para tener en cuenta

No se ejecutan conexiones externas, fórmulas volátiles o bloqueadas ni macros. No se adivinan fechas ambiguas ni identificadores con ceros iniciales. Primero se marcan las filas duplicadas; la limpieza nunca elimina filas. Un servicio de API requiere una vista previa separada y permiso de envío de una sola vez para las celdas mostradas. Aceptar los cambios sigue requiriendo otra acción explícita. Deshacer revierte una transacción aceptada. Comprueba los resultados.
