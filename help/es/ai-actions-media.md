# Acciones de IA para audio y video

Abre un archivo de audio o video compatible y elige Transcribir. Selecciona inglés, español o detección automática y, si hace falta, un intervalo más corto. Revisa la transcripción. Selecciona un tiempo para ir a ese punto sin iniciar la reproducción automática. Resumir audio o video y Buscar momentos usan la transcripción revisada; escribe una descripción para Buscar momentos. Guarda una copia como texto, SRT o VTT, o revisa los subtítulos en el editor multimedia antes de aplicarlos.

## Cómo usarlo

El reconocimiento de voz se procesa localmente con Herramientas de voz, sin necesitar el paquete del asistente. Puede reconocer palabras incorrectas y no identifica a las personas que hablan. El servicio elegido para el asistente procesa resúmenes y búsquedas; una API necesita una revisión aparte del contenido y la acción Enviar. Cada solicitud admite hasta una hora de transcripción. Exportar una transcripción no modifica el archivo multimedia.
