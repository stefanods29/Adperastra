# Ver PDF

Lee PDF sin salir del Explorador.

## Cómo usar

- Abre un PDF.
- Usa **Página anterior**, **Página siguiente** o **Número de página** para navegar.
- Abre **Miniaturas** o **Esquema** para moverte por el documento.
- Elige **Ajustar al ancho**, **Ajustar a la página** o un nivel de zoom.
- Selecciona texto para copiarlo o usa Buscar.
- Elige **Imprimir…** y un intervalo de hasta 100 páginas para abrir la ventana de impresión.

## Para tener en cuenta

- No se ejecutan scripts ni recursos externos del PDF.
- Algunas páginas escaneadas no tienen texto seleccionable; el reconocimiento de texto se agrega por separado.
- Las contraseñas se conservan solo mientras el PDF está abierto.
- Los PDF muy grandes o dañados pueden necesitar otra aplicación.
- La vista previa no permite editar ni imprimir.

Consulta también: «Abrir archivos» y «Vista previa rápida».
