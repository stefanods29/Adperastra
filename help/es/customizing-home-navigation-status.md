# Personalizar Inicio, navegación y estado

Mantén cerca secciones y campos útiles.

## Cómo usar

Usa Editar Inicio para mostrar, mover y cambiar tamaños. En Panel de navegación elige filas, nombres visibles y ancho. En Barra de estado elige campos del Explorador y de cada tipo.

## Para tener en cuenta

Un nombre visible no cambia el nombre de una carpeta. Las secciones ocultas dejan de cargar contenido opcional. Los errores importantes siguen visibles aunque ocultes la barra de estado.

Consulta también: «Grupos guardados» y «Configuraciones compartibles».
