# Seleccionar con un recuadro

Selecciona varios elementos dibujando sobre el fondo de una carpeta.

## Cómo usar

Arrastra desde un espacio vacío sobre los elementos. Mantén Mayús para agregar o Ctrl para alternar elementos. Suelta para terminar o pulsa Esc para cancelar.

## Para tener en cuenta

Arrastrar desde un elemento inicia el arrastre normal de archivos. Acercarte a un borde desplaza la selección.

Consulta también: «Seleccionar archivos» y «Modos de vista».
