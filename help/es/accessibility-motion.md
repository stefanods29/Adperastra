# Movimiento y comodidad

Limita animación, reproducción automática e interrupciones.

## Cómo usar

Elige Reducir movimiento, desactiva reproducción automática o entra en Distribución de concentración. Los sonidos siguen siendo opcionales.

## Para tener en cuenta

El movimiento reducido de Windows tiene prioridad. La aplicación no hace parpadear contenido ni cambia el enfoque por avisos normales. Salir restaura los paneles anteriores.

Consulta también: «Accesibilidad».
