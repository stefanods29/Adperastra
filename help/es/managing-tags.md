# Administrar etiquetas

Mantén un catálogo reutilizable de nombres.

## Cómo usar

- Abre Administrar etiquetas para crear, renombrar, combinar, eliminar, importar o exportar.
- Revisa conflictos al importar.
- Las ubicaciones personales se excluyen salvo selección.

## Para tener en cuenta

- Eliminar una etiqueta no elimina archivos.
- Combinar y eliminar admiten Deshacer dentro del historial conservado.

Consulta también: «Etiquetas» y «Carpetas inteligentes».
