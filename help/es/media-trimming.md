# Recortar y cortar multimedia

Elige **Editar multimedia** para crear una receta y conservar el original.

## Cómo usar

Configura **Inicio** y **Fin** para recortar la duración, **Cortar selección** para quitar un intervalo o **Dividir en el cabezal** para separarlo. Deshacer restaura un cambio. Guardar receta de edición conserva las instrucciones; Exportar multimedia crea un archivo reproducible.

Consulta también: «Exportar contenido multimedia».
