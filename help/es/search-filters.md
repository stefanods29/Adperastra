# Filtros de búsqueda

Combina propiedades sin escribir código.

## Cómo usar

- Elige **Filtros**, agrega tipo, tamaño, fechas, carpeta o metadatos y elige **Todos** o **Cualquiera**.
- Revisa la consulta antes de guardarla.

## Para tener en cuenta

- Las fechas se resuelven a un intervalo fijo para la consulta capturada.
- Los campos no compatibles se rechazan.

Consulta también: «Buscar».
