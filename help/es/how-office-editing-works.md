# Cómo funciona la edición de archivos de oficina

Edita archivos de oficina compatibles con los controles de Adperastra y un motor local.

## Cómo usar

- Abre un archivo compatible y elige **Habilitar edición** cuando aparezca.
- Usa la cinta para editar y luego elige **Guardar** o **Guardar una copia…**.
- Usa **Compatibilidad y límites** para revisar qué puede editar o conservar el motor.

## Para tener en cuenta

El motor es opcional. Los archivos de internet comienzan en vista protegida. No se ejecutan macros ni conexiones de datos externas. Parte del contenido puede conservarse sin poder editarse. Si no se puede conservar de forma segura, usa una copia compatible o tu aplicación elegida.

Consulta también: «Compatibilidad y límites de archivos» y «Cambios sin guardar y recuperación».
