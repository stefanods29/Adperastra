# Carpetas inteligentes

Conserva una vista activa de una búsqueda.

## Cómo usar

- Guarda una búsqueda y elige Guardar como carpeta inteligente.
- Ábrela desde Inicio o navegación.
- El índice actualiza los resultados.

## Para tener en cuenta

- No es un destino en disco.
- Quitarla conserva los archivos y, de forma predeterminada, la consulta.

Consulta también: «Buscar».
