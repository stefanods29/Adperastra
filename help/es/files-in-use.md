# Archivos en uso

Revisa qué programas informa Windows que mantienen abierto un archivo.

## Cómo usar

Elige **¿Qué está usando esto?**. Revisa la lista. Guarda el trabajo en un programa antes de elegir **Pedir al programa que cierre** y confirma. Vuelve y elige **Reintentar acción**.

## Para tener en cuenta

La aplicación nunca fuerza el cierre. Los programas protegidos no se pueden cerrar aquí. Revisar una carpeta no inspecciona todos sus archivos. Una lista vacía no demuestra que el archivo pueda cambiarse.

Consulta también: «Copias y conflictos» y «Guardar archivos».
