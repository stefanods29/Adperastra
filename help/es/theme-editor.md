# Editor de temas

Crea una apariencia local y revísala antes de aplicarla.

## Cómo usar

1. Abre **Configuración > Editor de temas**.
2. Parte de un tema predeterminado, cambia los colores y opciones indicados y elige **Guardar tema**. La vista previa de la derecha usa tu borrador; el resto de la aplicación conserva su aspecto actual hasta que guardes.
3. **Importar tema** abre una vista previa; no lo aplica de inmediato. Revisa los colores y elige **Guardar tema** cuando quieras conservarlo.
4. **Exportar tema** escribe un archivo `.adptheme`. Puedes incluir la imagen de fondo; el archivo nunca contiene la ruta de la carpeta de la imagen original.

## Para tener en cuenta

- Solo se importan datos seguros. Un tema guarda colores, tamaños, espaciado y una selección de fuentes instaladas. No puede ejecutar CSS, scripts ni programas.
- Las fuentes instaladas se indican por nombre y no se incluyen al exportar temas. Adperastra nunca copia ni redistribuye archivos de fuentes.
- Los materiales no compatibles usan un fondo sólido. El contraste alto de Windows también mantiene una superficie sólida.
- La sección **Estilo personalizado** solo acepta las propiedades indicadas de esquinas y espaciado. No acepta CSS arbitrario.
- Los colores que no cumplen los requisitos de contraste se rechazan al guardar. Puedes ajustar el color o dejar que el editor elija uno legible.
- Los temas predeterminados nunca se sobrescriben. Un tema personalizado guardado es un tema local aparte.

Consulta también: «Temas diurnos y nocturnos» y «Colores de énfasis».
