# Ver cuadernos

Lee las celdas y los resultados guardados de un cuaderno.

## Cómo usar

Abre un cuaderno y expande el resultado que quieras revisar. Usa Buscar para encontrar texto visible. El código nunca se ejecuta.

## Para tener en cuenta

No se muestran los resultados interactivos o inseguros.

Consulta también: «Ver texto» y «Vista previa rápida».
