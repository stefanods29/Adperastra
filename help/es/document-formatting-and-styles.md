# Formato y estilos

Mantén un formato uniforme.

## Cómo usar

Selecciona texto para cambiar la fuente o párrafos para ajustar alineación, espaciado y estilos. Elige un estilo en **Inicio**; usa **Crear estilo** para un estilo reutilizable del documento. **Disposición** cambia el tamaño de página, márgenes y columnas de la sección actual.

## Para tener en cuenta

Un control vacío o mixto indica que la selección tiene valores distintos. Abrir un selector no aplica un valor.

Consulta también: «Editar documentos» y «Compatibilidad y límites de archivos».
