# Ver imágenes HEIC y AVIF

Ve imágenes en formatos modernos compatibles.

## Cómo usar

- Abre la imagen normalmente. HEIC y HEIF usan el códec de Windows instalado en este equipo.
- AVIF sigue usando el visor de imágenes normal cuando la vista web de Windows lo admite.
- Si falta un códec compatible, revisa las instrucciones de Windows o elige tu aplicación de imágenes habitual.
- Usa los controles de zoom y rotación como con cualquier otra imagen.

## Para tener en cuenta

- Adperastra no compra ni instala códecs automáticamente.
- Tu imagen no cambia.
- El tipo de archivo se revisa por su contenido, no solo por su nombre.
- Un códec faltante se muestra con un aviso claro, nunca como una imagen vacía.

Consulta también: «Ver imágenes» y «Aplicaciones predeterminadas».
