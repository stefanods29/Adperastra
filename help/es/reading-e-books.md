# Leer libros electrónicos

Lee libros electrónicos locales en una pestaña.

## Cómo usar

Abre un libro compatible. Usa Anterior, Siguiente o Tabla de contenido para navegar. Cambia Tamaño de fuente o Tema de lectura para leer con comodidad.

## Para tener en cuenta

Los libros no pueden ejecutar scripts ni cargar imágenes remotas. Los libros protegidos pueden necesitar otra aplicación.

Consulta también: «Vista previa rápida» y «Abrir archivos».
