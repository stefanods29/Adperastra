# Modos y prefijos de búsqueda

Elige qué busca una consulta.

## Cómo usar

- Selecciona **Nombre**, **Contenido**, **Filtros** o **Expresión regular**.
- **Ctrl+Tab** cambia de modo con el campo enfocado.
- Los prefijos `name:`, `text:` y `re:` eligen un modo.

## Para tener en cuenta

- Los modos opcionales de IA solo están disponibles tras activar cada permiso y preparar sus paquetes locales.
- El contenido requiere consentimiento explícito de indexación.

Consulta también: «Indexación y privacidad».
