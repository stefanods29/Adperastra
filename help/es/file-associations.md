# Asociaciones de archivos

Elige los tipos de archivo para los que quieras ofrecer Adperastra en **Abrir con**, sin cambiar tus aplicaciones predeterminadas.

## Cómo usar

- Abre **Configuración > Integración con Windows** y selecciona los tipos para los que quieras ofrecer Adperastra en **Abrir con**.
- Usa **Elegir aplicaciones predeterminadas…** para decidir en Configuración de Windows.

## Para tener en cuenta

- Instalar Adperastra nunca reemplaza silenciosamente tus aplicaciones predeterminadas.
- La desinstalación quita las entradas propias que coincidan y conserva las cambiadas por otro programa.
- Desactivar un tipo quita solo la entrada de Adperastra para ese tipo.

Consulta también: «Integración con el Explorador de Windows».
