# El asistente

Pregunta sobre archivos permitidos o solicita una acción sugerida de la aplicación.

## Cómo usarlo

Abre **Asistente** con Ctrl+Alt+A. Elige **IA local** o **Clave de API**, escribe un mensaje y elige **Enviar**. Usa **Detener** para terminar una respuesta. Revisa una sugerencia y elige **Aplicar** solo si sus cambios exactos son correctos. Abre un botón de origen para comprobar una página o un momento.

## Conviene saber

El contenido de archivos no concede permisos. El asistente puede equivocarse. El modo de API envía solo contenido aprobado al proveedor elegido y puede generar cargos. Cambiar de proveedor inicia otro chat.

Consulta también: "Funciones del asistente" y "Preferencias y privacidad del asistente".
