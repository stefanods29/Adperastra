# Fórmulas

Escribe fórmulas en el idioma de la aplicación.

## Cómo usar

Comienza con el signo igual. Usa **Insertar función** para revisar las funciones disponibles. Confirma la fórmula y revisa el resultado.

## Para tener en cuenta

Los nombres y separadores pueden cambiar según el idioma; la fórmula guardada conserva su significado. Las funciones no compatibles pueden mostrar valores guardados sin recalcular. El texto pegado que parece una fórmula se conserva como texto.

Consulta también: «Editar hojas de cálculo» y «Ordenar y filtrar».
