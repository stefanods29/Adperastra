# Pegar como archivo

Cuando el portapapeles contiene texto o una imagen en lugar de archivos, **Pegar como archivo** lo guarda como un archivo nuevo en la carpeta abierta.

## Cómo se usa

- Copia un texto o haz una captura de pantalla (por ejemplo con Win+Mayús+S).
- En una carpeta, haz clic derecho en un espacio vacío y elige **Pegar como archivo**.
- El archivo nuevo aparece con su nombre seleccionado, para que puedas cambiarlo de inmediato. Se puede deshacer como cualquier otra acción.

## Qué se crea

- **El texto** se convierte en un archivo de texto. Si parece Markdown (títulos, bloques de código, enlaces o una tabla Markdown), recibe la terminación `.md`; si parece una tabla con comas, puntos y comas o tabulaciones, recibe `.csv`; si no, `.txt`.
- **Las imágenes y capturas** se convierten en archivos `.png`, o `.jpg` si elegiste JPG en **Configuración** > **Imágenes pegadas**.
- Los nombres siguen el estilo de Windows, por ejemplo «Imagen pegada 2026-10-28 14-05.png». Si el nombre está ocupado, se agrega un número.

Si el portapapeles contiene archivos, **Pegar como archivo** los pega como un pegado normal.

Consulta también: «Copiar y mover archivos» y «Deshacer».
