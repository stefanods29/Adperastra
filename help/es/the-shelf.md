# La bandeja

Reúne referencias de varias carpetas sin mover sus archivos.

## Cómo usar

Abre **Bandeja** con Ctrl+Alt+S. Suelta archivos allí o elige **Agregar a la bandeja**. Selecciona elementos y elige copiar, mover, comprimir, compartir, convertir, limpiar privacidad o abrir como grupo de pestañas. Cada acción abre su revisión normal.

## Para tener en cuenta

Quitar o vaciar referencias no elimina archivos. La lista permanece tras reiniciar; los elementos movidos o ausentes pueden necesitar Actualizar. Los elementos de carpetas bloqueadas permanecen solo en memoria.

Consulta también: «Acciones en lote» y «Grupos guardados».
