# Convertir archivos

Crea un archivo nuevo en otro formato.

## Cómo usar

Selecciona archivos y elige **Convertir en…**. Elige un formato, revisa la vista previa y las opciones y selecciona una carpeta de destino. Revisa los cambios indicados de calidad, transparencia, animación o metadatos. Elige **Convertir**. Usa Cancelar para detener el trabajo pendiente.

## Para tener en cuenta

- Se conservan los archivos originales.
- No se reemplazan archivos existentes.
- Algunos formatos no conservan todos los metadatos.
- Los archivos que ya terminaron siguen disponibles si cancelas el resto.
- Los cambios sin guardar se capturan para exportarlos sin guardar sobre el original.

Las opciones de PDF, documentos, tablas y archivos comprimidos aparecen cuando son compatibles.

Usa **Intervalo de páginas** para elegir páginas PDF y **Hoja** para elegir datos de un libro. Las celdas de texto que podrían actuar como fórmulas necesitan el prefijo de seguridad indicado. Aquí no se evalúan fórmulas.
