# Crear diapositivas con IA

Convierte contenido seleccionado en un borrador revisado con disposiciones reales.

## Cómo usar

Elige Crear diapositivas a partir de un documento, esquema o notas, un estilo y el número de diapositivas; revisa después el esquema estructurado. También puedes agregar una diapositiva, acortar texto seleccionado, escribir notas del orador, sugerir una disposición o sugerir un estilo. Edita el esquema, revisa la vista previa real y corrige el contenido que no cabe o los datos cambiados. Aceptar borrador crea una presentación sin guardar con Deshacer; las demás acciones cambian solo el alcance revisado. Elige Guardar una copia para crear un archivo separado.

## Para tener en cuenta

El modelo aporta texto y sugerencias de imágenes; la aplicación construye las diapositivas reales. No se descargan imágenes automáticamente. Comprueba datos, nombres, números y anclajes de origen. Un servicio de API requiere una vista previa separada y permiso de envío de una sola vez, seguido de otra acción de aceptación. No se envía contenido sensible desbloqueado. Puedes cambiar de estilo después con Deshacer. No se ejecuta entrenamiento automático.
