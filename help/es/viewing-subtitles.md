# Ver subtítulos

Revisa los tiempos y el texto de los subtítulos.

## Cómo usar

Abre un archivo SRT o VTT. Elige una fila o usa Buscar para encontrar palabras.

## Para tener en cuenta

Se informa de los subtítulos no válidos; abrir el archivo no reproduce ni cambia un video.

Consulta también: «Reproducir audio y video» y «Ver texto».
