# Formato y formato condicional

Da formato a las celdas seleccionadas.

## Cómo usar

Usa **Inicio** para fuente, alineación, formato de número y estilos. El formato condicional aplica una apariencia cuando se cumple una regla. Revisa el intervalo y la regla antes de confirmar.

## Para tener en cuenta

El formato cambia la presentación, no el valor subyacente. Los controles mixtos indican configuraciones distintas en la selección.

Consulta también: «Editar hojas de cálculo» y «Fórmulas».
