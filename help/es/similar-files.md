# Archivos similares
Encuentra archivos indexados con contenido relacionado.

## Cómo usarlo
Selecciona una foto o un documento, elige **Archivos similares** y revisa los resultados. Las fotos comparan contenido visual; los documentos comparan texto extraído con permiso. La similitud no demuestra que sean duplicados. Un origen desbloqueado requiere permiso separado para una sola comparación en memoria y nunca se indexa. El razonamiento por API envía solo el contenido mostrado tras una confirmación de envío separada y de una sola vez.

Consulta también: «Buscar fotos por contenido» y «Buscar duplicados».
