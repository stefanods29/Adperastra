# Etiquetas

Identifica archivos sin cambiar sus nombres.

## Cómo usar

- Selecciona elementos, elige Agregar etiquetas y aplica nombres.
- Usa Detalles o Administrar etiquetas para quitar, renombrar, recolorear o combinar.

## Para tener en cuenta

- Se guardan en este perfil y usan identidades verificadas.
- La aplicación puede conservarlas al copiar o mover; algunos movimientos externos no se pueden seguir.
- Los metadatos incrustados son una copia explícita independiente.

Consulta también: «Administrar etiquetas».
