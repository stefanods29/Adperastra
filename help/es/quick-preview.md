# Vista previa rápida

Mira un archivo sin abrir otra pestaña.

## Cómo usar

- Selecciona un archivo y presiona **Espacio**.
- Usa **Izquierda** y **Derecha** para ver los archivos cercanos.
- Presiona **Espacio** o **Esc** para cerrar la vista previa.
- Elige **Abrir** para abrir el archivo normalmente.

## Para tener en cuenta

- Las vistas previas no editan tus archivos.
- Los archivos solo en línea muestran un aviso de nube hasta que elijas Abrir.
- Algunos formatos todavía no tienen vista previa.

Consulta también: «Abrir archivos» y «Detalles de archivos».
