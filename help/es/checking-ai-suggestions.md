# Revisar las sugerencias de IA

Lee las referencias y los avisos de cobertura parcial. Comprueba los nombres, importes y fechas importantes en el original. Revisa las imágenes antes de aplicarlas y las transcripciones antes de usarlas como subtítulos o texto. Enviar a una API autoriza una solicitud mostrada, pero no modifica el documento. Usa después Aplicar o Guardar una copia solo tras revisar el resultado. Descartar conserva el documento y sus archivos de origen sin cambios.

## Cómo usarlo

La IA puede inventar u omitir detalles. Las acciones no disponibles o experimentales no garantizan calidad. Las instrucciones dentro de un archivo se tratan como contenido del archivo. El modo local nunca cambia automáticamente a una API. No se envía contenido sensible desbloqueado a una API. Reintentar es tu decisión y puede generar otro cargo del proveedor. La aplicación no entrena automáticamente con tus archivos.
