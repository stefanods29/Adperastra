# Revisar ortografía

Revisa la ortografía con un corrector local disponible.

## Cómo usar

Abre **Revisar** y elige **Ortografía**. Revisa una palabra marcada y elige una sugerencia o déjala igual.

## Para tener en cuenta

El corrector usa el idioma del documento y la compatibilidad local instalada. El dictado es una acción explícita del paquete de voz; las sugerencias de IA llegan en20c y las solicitudes en línea requieren el consentimiento de envío de17a. Una sugerencia solo cambia el texto cuando la eliges.

Consulta también: «Editar documentos» e «Idiomas».
