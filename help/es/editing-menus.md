# Editar menús

Organiza comandos registrados sin cambiar su función.

## Cómo usar

Abre Configuración > Editar menús. Elige un destino, oculta u ordena elementos, crea submenús o separadores y revisa la vista previa. Aplica o restablece ese menú.

## Para tener en cuenta

La vista previa no ejecuta comandos. Los comandos ocultos siguen en la paleta si están disponibles. Las configuraciones no agregan scripts.

Consulta también: «Personalizar barras de herramientas».
