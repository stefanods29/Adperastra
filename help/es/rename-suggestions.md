# Sugerencias de nombres
Sugiere nombres más claros a partir de archivos seleccionados.

## Cómo usarlo
Elige **Sugerir un nombre**, revisa el patrón y edita o excluye cada nombre propuesto. Revisa la vista previa normal de renombrado masivo antes de ejecutar. Las extensiones y los archivos no cambian hasta esa acción explícita.

## Conviene saber
El contenido puede interpretarse mal. El razonamiento por API envía solo el contenido mostrado tras una confirmación de envío separada y de una sola vez.

Consulta también: «Renombrado masivo» y «Niveles de calidad de IA».
