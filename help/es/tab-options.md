# Opciones de pestañas

Elige cómo se ven las pestañas y dónde se abren.

## Cómo usar

Abre **Configuración > Opciones de pestañas**. Elige ancho, botón Cerrar, posición de pestañas nuevas y qué se activa al cerrar. Las vistas previas son opcionales.

## Para tener en cuenta

La pestaña permanente del Explorador sigue abierta. Las vistas previas son de solo lectura y no reproducen contenido. Los nombres completos siguen disponibles para herramientas de accesibilidad y descripciones.

Consulta también: «Trabajar con pestañas».
