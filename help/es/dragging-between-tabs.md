# Arrastrar entre pestañas

Cambia de vista mientras arrastras archivos.

## Cómo usarlo

- Mantén los archivos sobre una pestaña hasta que se abra.
- Suéltalos en una carpeta para usar la copia o el movimiento normal.
- Suéltalos en la barra de pestañas para abrirlos o en un grupo para abrirlos allí.

## Para tener en cuenta

- Un editor acepta solo inserciones compatibles.
- Si hay varias acciones posibles, elige una antes de cambiar el contenido.
- Cambia la demora en Configuración.

Consulta también: «Copiar contenido entre pestañas» y «Grupos de pestañas».
