# Sugerencias de organización
Revisa destinos sin movimientos automáticos.

## Cómo usarlo
Elige carpetas de destino aprobadas en **Configuración > IA**. Una sugerencia ofrece **Mover**, **Ahora no** o **Nunca para este tipo**. **Mover** abre la vista previa normal de operaciones. Solo los movimientos normales confirmados aportan recuentos locales por extensión; se excluyen los sensibles. **Restablecer el historial de destinos** está en Configuración. El razonamiento por API envía solo el contenido mostrado tras una confirmación de envío separada y de una sola vez.

Consulta también: «Mover archivos» y «Privacidad de IA».
