# Abrir archivos desde Windows

Abre archivos compatibles en la ventana de Adperastra que ya está abierta.

## Cómo usarlo

- Elige Adperastra en **Abrir con** de Windows.
- La aplicación comprueba los archivos y abre pestañas con tus preferencias normales.

## Para tener en cuenta

- Esto no cambia tus aplicaciones predeterminadas.
- Las opciones de registro llegan con la integración de Windows.
- Una solicitud rechazada u ocupada no modifica archivos.

Consulta también: «Abrir archivos» y «Aplicaciones predeterminadas».
