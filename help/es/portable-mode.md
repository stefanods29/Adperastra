# Modo portátil

Conserva los datos de la aplicación portátil junto a la aplicación.

## Cómo usar

Extrae el ZIP portátil en una carpeta donde puedas escribir e inicia Adperastra. Los datos se guardan en AdperastraData. Cierra la aplicación antes de copiar toda la carpeta portátil a otra unidad.

## Para tener en cuenta

Una carpeta de solo lectura necesita otra ubicación para los datos. Mover solo el ejecutable no mueve la configuración, el historial ni los paquetes. Conserva una copia de los archivos importantes y del historial de versiones.

Consulta también: «Instalar y actualizar».
