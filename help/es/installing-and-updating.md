# Instalar y actualizar

Instala Adperastra para tu cuenta de Windows o usa la versión portátil.

## Cómo usar

Descarga el instalador o el ZIP portátil desde la página de versiones del proyecto. Verifica primero la suma de comprobación. Ejecuta el instalador o extrae el ZIP portátil en una carpeta donde puedas escribir. Las actualizaciones son opcionales; la búsqueda abre la página de la versión y nunca instala nada automáticamente.

## Para tener en cuenta

Esta versión no tiene firma de código. Windows puede mostrar «Windows protegió su PC». Verifica la descarga antes de elegir «Más información» y «Ejecutar de todas formas». Las actualizaciones conservan la configuración y los archivos. Al desinstalar, se elige de forma predeterminada Conservar mi configuración y mis datos.

Consulta también: «Verificar una descarga» y «Modo portátil».
