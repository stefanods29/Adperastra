# Glossary: English to Spanish (es-419)

Spanish texts use Latin American Spanish, informal "tú", short and friendly, matching the strings already in `es.json`. Use these words every time; if a recipe gives the Spanish text, use the recipe's text.

## Style

- Sentences: "No se pudo abrir este archivo." (impersonal "se" for errors), "Escribe un nombre." (tú form for instructions).
- Buttons and commands: infinitive ("Guardar", "Abrir con…", "Extraer todo").
- Keep Windows names as Windows shows them in Spanish ("Este equipo", "Papelera de reciclaje").
- Ellipsis character `…` after commands that open a dialog, in both languages ("Open with…" / "Abrir con…").
- Keyboard names come from `keys.*` (Ctrl, Mayús, Alt, Entrar, Supr, Espacio).
