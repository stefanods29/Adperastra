## Fixed meanings

1. Grant/authority IDs are native-issued. Paths are not tokens. Disk/virtual/snapshot variants are explicit; browser cannot downgrade sensitivity.
2. Revision differs from content identity. Capture the specified tuple before async encoding. Saving R while editing R+1 cannot mark R+1 clean. Save copy differs from Save as new.
3. File bytes use grants/protocol, not JSON or Tauri Channel. Protocol ranges4MiB; upload chunks1MiB. Shared Jobs remains the single user-job transport. Scheduler admission precedes start acknowledgement.
4. Owned staging/no-replace publication reports actual effects. Replace stays unavailable until object-bound recycling/publication is proved. Model output does not directly mutate user files.
5. Future settings11→56; screenshots57–202, see GUIDE_STATUS. Running settings remain11.
6. Optional API mode is selected explicitly, Meta first; keys are native. One-use approval binds exact payload/provider/model/source revision. No cloud fallback. Speech/image/embeddings stay local; text consumers use17a's selected-backend gateway.
