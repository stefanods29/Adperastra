This is a **guide** step: exact names, decisions and tests are prescribed, without implementation code. Workers author owned files/tests; the coordinator integrates and executes verification. Image processing, speech and captions stay local. Text/vision assistant actions follow the selected Local AI/API backend and17a's separate source-sending approval; API is never an automatic fallback.

## Goal

Preview optional image cleanup, document summaries/translations, audio/video transcripts and moments, comparisons and folder summaries. Install speech or image packs independently of the assistant. Turn on local automatic captions while watching media, and explicitly dictate a short passage for a later editor review.
