## Goal and exclusions

See logical/allocated storage totals, largest items and a treemap; review verified duplicate groups before any cleanup; show optional asynchronously calculated folder sizes. No automatic deletion, permanent deletion, deduplication/reflink rewriting, NTFS compression, cloud hydration, network scanning by default or AI similarity. Source equality means verified identical bytes, not perceptual similarity.
