## Goal and exclusions

Convert audio/video and supported documents using explicitly installed, replaceable packs. Inspect/remove selected hidden information with truthful coverage. No Office editing engine decision (20a), AI, online conversion, arbitrary CLI options or automatic external tools. User-installed Pandoc is not bundled or executed in this scope because R-LIC forbids adding it; the earlier candidate is excluded rather than silently adopting GPL tooling.

## Decisions

1. D1. Coordinator produces pack builds from pinned verified inputs, inventories all runtime licenses/notices/source links and freezes final archive/file hashes in the signed12a catalog. FFmpeg configuration excludes GPL/nonfree components and networking; no x264/x265/GPL filters. Admit only encoders actually enumerated in the audited build. Required minimum: PNG/GIF/PCM/FLAC, MP3 via an allowed replaceable-program build, VP9/Opus; AV1/Vorbis and OS H264/HEVC/AAC offered only after actual capability probe. No generic claim that every FFmpeg build is LGPL.
2. D2. EngineHost owns native process launch, bounded stdin/stdout/stderr, kill-on-close job, memory/CPU caps and timeout. It uses a Windows AppContainer with zero network capabilities and read access only to verified pack/system runtime plus the private job input/output/profile directories; never grant the user's parent folder. CreateAppContainerProfile/DeriveAppContainerSidFromAppContainerName and STARTUPINFOEX security capabilities are available in windows0.61.3 Win32_Security_Isolation/Win32_System_Threading. Existing HelperProcess alone is not a sandbox. If the exact engine cannot run inside these restrictions, capability registration fails closed; no unrestricted retry. Coordinator runs filesystem/network denial probes before enabling a pack.
3. D3. Ordinary disk inputs are copied from the same guarded source handle into an exclusively created owned private job directory. Validate size/stamp before/after; source never modified. Sensitive snapshots/documents are refused with engines.sensitive_unsupported because these CLI engines require plaintext files. No plaintext sensitive spool, profile, proxy or diagnostic. Native input/output descriptors, not user command strings, determine process arguments; quote Windows arguments by the documented CreateProcess argument algorithm and test Unicode/quotes/backslashes. No shell or inherited arbitrary environment.
4. D4. Probe uses ffprobe with bounded JSON; maximum1MiB result,64streams,512tags,tagvalue4KiB. Media source<=32GiB, duration<=24h, dimensions<=16384 and max100MP, channels<=32. Default job memory1GiB, one media and one Office process concurrently; probe15s, preview10s, Office120s, render/export up to24h with heartbeat timeout30s. Progress keys from `-progress pipe:1`, `-nostdin`; clamp monotonic completed time, never treat stderr text as successful completion. Cancellation closes stdin then terminates job within5s. Parent validates output with independent probe before owned publication.
5. D5. Time unit is integer microseconds (TimeUs) <=Number.MAX_SAFE_INTEGER; rational frame rate numerator/denominator positiveu32, reduced, denominator<=100000. Start inclusive/end exclusive. For re-encode choose first frame timestamp>=start and frames with timestamp<end; audio sample interval ceil(start_us*rate/1e6) to ceil(end_us*rate/1e6). Stream copy trim is offered only when keyframe-aligned and explicitly shown approximate; exact trim defaults re-encode. This timing contract is reused15/19, never rounded through floating milliseconds.
6. D6. Register converter IDs media/video,media/audio,media/gif,office/pdf,office/html,office/txt,office/md,document/docx. Extend FormatId additively with webm/mp4/mkv/mov/gif/mp3/opus/ogg/flac/wav/aac/docx/xlsx/pptx/odt/ods/odp/rtf/doc/xls/ppt/txt; compatible options are08a MediaConversionOptions/OfficeConversionOptions. Metadata stays by default; losses listed before acceptance. GIF has explicit audio/transparency/frame-rate loss report. Preview uses at most3s at512edge and returns leased cache artifact; no conversion of a full file merely to preview it.
7. D7. LibreOffice launches `soffice.com` with --headless/--nologo/--nodefault/--norestore/--convert-to and --outdir, a unique URI-encoded -env:UserInstallation, approved filter IDs only. Its pack-owned finalized profile sets Common/Security/Scripting.DisableMacrosExecution=true, DisableActiveContent=true, MacroSecurityLevel=3, no trusted locations; Java/extensions/update checks disabled. Source package preflight rejects external OOXML/ODF relationships and DDE/external data sources; legacy binary inputs are confined by AppContainer even when their internal links cannot be fully inspected. No network or user-folder access. Headless alone is never the macro policy. Official schema source: LibreOffice core tag libreoffice-26.8.2.2 officecfg/registry/schema/org/openoffice/Office/Common.xcs.
8. D8. Office conversions preserve input and use owned temporary outputs. Never infer success from exit0 alone: expected output must exist, boundedsize<=1GiB, valid detected format, readable by independent parser, and no unexpected extra artifacts. `writer_pdf_Export`, `calc_pdf_Export`, `impress_pdf_Export` are fixed per family; unsupported exact filter/format returns unavailable, not HTML mislabeled PDF. Markdown routes reuse08b normalized blocks and sanitized HTML, no new unverified mammoth/turndown dependency.
9. D9. Privacy categories extend08a additively: last_modified_by/company/tracked_changes/hidden_text/speaker_notes/encoder. Office removal rewrites bounded ZIP/XML in helper preserving unrelated parts/relationships; removing comments/tracked changes/hidden text/notes requires content-change acknowledgment. For tracked changes, chosen policy is accept-current-visible-content; deletions removed, insertions retained, then change markup removed. Unknown change/content structures fail unverified. Media cleaning remuxes only, selected metadata keys removed, no transcode without acknowledgment. Archive comments/timestamps reuse guarded archive conversion; timestamps only when explicitly selected. Reinspect and compare unselected categories/content before publication.

### E6: native conversion dispatch with the shared pure output sink

Canonical native `src-tauri/src/engine_conversion.rs` exports run_engine_conversion(host:&EngineHost,request:&ConversionRequest,inputs:Vec<EngineInput>,output:&mut dyn convert::ConvertOutputSink,context:&JobContext)->Result<convert::PreparedOutput,convert::ConvertError>. It borrows host/sink/context only for this synchronous blocking-worker invocation and owns inputs until source/output verification completes. At most1000 inputs per combine invocation; each mode follows08a. Source caps32GiB media/512MiB Office, output total32GiB media/1GiB Office, timeouts D4, cancellation inherited from JobContext. EngineHost adds no Tauri dependency to the pure convert crate.

The parent08a dispatcher resolves/guards authorized inputs once, then selects this native branch only for registered engine_id media/office; all other converters keep08a's pure helper route. The coordinator adds this one dispatch branch in native convert.rs; no UI component invokes engines. Request validation/naming/loss acknowledgement/report/history/publication remain08a's runner. This function calls EngineHost.run, validates each owned EngineOutput against expected format/hash/length and input association, rewinds OwnedOutput.file_mut() to byte0, then passes OutputDraft/name_part and1MiB chunks through the same borrowed ConvertOutputSink begin/write/finish/abort interface. It never calls publish_name/publish_to on EngineOutput and never writes the user's destination directly. Sink.finish performs common08a final warning/metadata/identity/no-replace checks before publication. Drop/dispose only engine-owned temporary outputs after copy or failure. A later failure preserves actual earlier sink outputs for08a's normal partial report; PreparedOutput counts only accepted finished outputs.

For12b registered media/office converter specs, input_mode is exactly each: one EngineInput and exactly one output per invocation; batch inputs are separate08a invocations in their original order. More or fewer engine artifacts fail before sink.begin. EngineSession.render_document is a separate read-only viewer API and does not change this conversion cardinality. Construct OutputDraft with name_hint=EngineOutput.relative_name (display only), name_part=none, mime=the independently detected expected output MIME and input_indices=[EngineInput.input_index]. Parent08a derives the actual final name; no engine path is trusted as a destination. Build OutputMetadata.byte_len/hash_sha256 from the verified owned file, width/height from independent image/video probe or None for documents/audio, metadata_lost from the independently verified source/output comparison, and warnings from the required typed warning analysis for that exact input/options. The latter must include every observed loss, match the preview/acknowledgements and refuse unexpected unaccepted changes before publication. One successful finished output returns PreparedOutput outputs_count1; totals and warning/loss unions come from that verified metadata. Missing/extra output, MIME mismatch or failed source/output inspection aborts the borrowed sink and never creates a success receipt. EngineResult metadata/stderr are evidence to check, not sufficient authority to declare preservation.

crates/convert/src/media_adapter.rs contains only media_converter_spec(id:ConverterId,available:bool,preserves:&[MetadataCategory])->Result<ConverterSpec,ConvertError> and validate_media_options(options:&MediaConversionOptions)->Result<(),ConvertError>. It imports pure08a types only; EngineCapability/EngineHost/EngineInput/OwnedOutput/JobContext remain native. Native code supplies audited availability and preservation lists. There is no convert-to-Tauri dependency, copied shared type or fictitious pure Converter implementation that secretly launches an engine.

The later19b E6 reserves the additive EngineRequest tag render_timeline and the native TimelineEngineRenderRequest/TimelineEngineSource/ValidatedRenderGraph types owned by19b.12b does not compile against future modules or offer that capability.19b integration extends this enum and EngineHost dispatch together through the coordinator; a graph cannot be smuggled into convert_media options. All existing engine variants and constraints remain unchanged.

### E8: typed media warning extension

This step extends canonical08a ConversionWarningCode with audio_loss and frame_rate_change, preserving all existing codes and limits. Matching locale keys convert.audioLoss = “Audio will not be included in this output.” / “El audio no se incluirá en este archivo.”; convert.frameRateChange = “The frame timing will change in this format.” / “El ritmo de los fotogramas cambiará en este formato.” Native/UI import the same enum. GIF requires audio_loss when an audio stream exists, palette_reduction when quantization changes colors, transparency_loss when nonbinary alpha cannot be preserved, and frame_rate_change when source timestamps cannot be represented exactly in GIF's10ms units. Include actual required codes in preview and request accepted_warning_codes; missing acknowledgement fails convert.warning_required before output.begin. Never treat MetadataCategory[] as consent for these visible/audible changes. T4 adds extension/translation wiring through coordinator and tests audio_without_ack_zero_output_begin, gif_fractional_alpha_requires_ack, gif_33333us_requires_frame_rate_change, gif_20000us_exact_timing and unknown_warning_refused.

Errors engines.bad_request/pack_missing/unsafe_build/sandbox_failed/sensitive_unsupported/busy/timeout/unsupported/changed/cancelled/failed; map capabilities to explicit reason. All native public commands ensure_main/validate/allowlist; runJob result is completion.
