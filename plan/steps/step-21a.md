Guide only. Coding workers write owned code/tests without installing, compiling, running tests, launching engines or app. Coordinator supplies shared wiring and executed verification. All UI consumes the exact engine-neutral20a adapter; no worker selects an engine or invents formula/import APIs.

## Goal and exclusions

Edit cells, formulas, formatting, sheets, charts and pivot tables with a movable ribbon and a responsive large-sheet grid. Preserve unsupported workbook content or refuse unsafe saving. No21b AI/formula assistant, external data refresh, macro/VBA execution, DDE, online functions, paid spreadsheet engine I/O or conversion of formulas to unrelated cached values without disclosure. Generic cross-tab formulas paste as text under09c revision1.

## Read first

Full20a values/SheetOperation/formula services/controller/compatibility,09a controller factory,09c transfer,09h recovery,13 office-sheet handler, design-spec Excel frame, CommandRegistry/Ribbon/ToolbarDock, current06f CSV table viewer. This is not an extension that makes the existing CSV viewer silently edit XLSX; its existing handler/service remains intact.

## Decisions

- D1. Upgrade canonical13 handler `office-sheet` with an optional editing presenter when20a approves sheet capabilities; retain OfficePresenter fallback. XLSX/ODS writable only with actual preservation proof; legacy XLS remains view-only unless approved. One source/controller, multiple views with independent selection/scroll; previewOnly cannot acquire writable commands.
- D2. Name box104x26px, formula bar36px, column headers26px, row-header44px, default rows22px, cells padding0/8px; sheet strip36px. Grid virtualizes both axes, overscan8rows/2columns, at most2,000 mounted visible cells; native tiles/cell pages bounded below.100,000-row scrolling must meetSmooth tier, no100,000-row array sent to React. Screen reader uses logical row/column counts and a bounded accessible window, activecell aria-activedescendant.
- D3. Formula bar is a local edit buffer. Enter/Confirm commits one set_cells transaction; Esc/Cancel restores original input without mutation. F2 edits the active cell; Tab/Enter after success moves selection, never before a failed commit. Name box accepts A1 or one named range, validates against live sheet dimensions, and changes selection only. Ctrl+Enter fills current selection with one validated input transaction within100,000-cell cap.
- D4. Canonical formula representation is engine-parsed AST serialized using English function IDs, comma argument separator, period decimal separator and leading '='. Display locale en-US uses SUM/comma; es-419 uses SUMA/semicolon and period decimal separator. Function-name maps come from20a E17 officeFunctions and the approved engine catalogue, not string replacement; Insert function uses that same typed catalogue. Strings, quoted sheet names, array constants and structured references retain token meaning. Unsupported functions remain preserved-only with cached values clearly labeled; their evaluation never silently becomes0.
- D5. Recalculation has no network/external workbook access or volatile external commands. Mandatory parity corpus includes SUM,AVERAGE,MIN,MAX,COUNT,COUNTA,IF,AND,OR,NOT,SUMIF,COUNTIF,VLOOKUP,INDEX,MATCH,ROUND,DATE andTODAY; TODAY uses injected local date in tests. Locale language does not alter stored numerical value. Date system1900/1904 is preserved;1900 leap-year compatibility is engine-controlled and tested, not reimplemented in UI.
- D6. Sorting always previews the full selected rectangle and header choice; it never sorts one selected column independently without explicit confirmation. Filtering stores typed predicates; hidden rows remain in source data. Merging warns about nonempty covered cells before approval. Range paste exceeding dimensions, cell budget or sheet protection fails before edits. Formula strings beginning'=' imported as TransferCell.text remain text unless separate explicit trusted formula route is advertised; this guide does not enable that route.
- D7. Number formats, validation and conditional rules are typed20a operations; mixed formatting remains indeterminate. Charts only reference current workbook ranges; pivots use selected source rectangle and explicit target address with overwrite review. Unsupported styles/charts/pivots/validation are preserved-only and controls disabled. No “refresh external data” action.
- D8. Sheet names1-31characters, unique ignoring case, refuse : / \\ ? * [ ]; at least one visible sheet. New sheets insert after active, named localized Sheet {index}, choose lowest available positiveindex. Hidden sheets stay in document and can be shown by explicit menu. Sheet reordering is one Undo transaction; coloring uses document color, not filesystem folder color.
- D9. Protected downloaded files start viewing. Enable editing, save, safe copy, autosave2s/debounced serialized saves and recovery follow20a/09a/09h. Editing local cells is not permission to overwrite an externally changed source. SaveCopy leaves original dirty. Settings schema52 -> 53 adds `sheet_editor.show_formula_bar` true, `sheet_editor.show_gridlines` true, `sheet_editor.show_headings` true, `sheet_editor.default_zoom`100 validated25-400; no formula model/AI preference.
