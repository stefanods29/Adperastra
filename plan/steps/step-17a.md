This is a **guide** step: every decision is below, but no implementation code. Workers write owned files/tests only; coordinator owns shared integration and executed verification. Local processing remains the default. The owner's API-key option adds an explicit, consented network path; it is not an automatic fallback.

## Goal

Use an optional assistant in English or Spanish to ask about selected files and propose normal app commands. Choose Local AI or an API key, with Meta first in the API provider list. Review every file change, control exactly which folders can be read and which excerpts may leave the computer, and stop processing at any time.

## Do not do in this step

17b supplies packaged image/speech/actions;17c semantic indexes and organization;17d scan extraction/writing;20c/21b/22b editor-specific proposals. Reserve unavailable tool capabilities until their real producers exist. No shell, macros, browser automation, arbitrary network tool, permanent deletion, automatic paid retry, automatic history upload, cloud embeddings, model training or remote filesystem execution. No Meta Files/Responses server-side state or built-in web_search/tool_search. Recycle execution stays unavailable under09f's unproved object-bound recycle limitation; a preview is not evidence of safe deletion or completed milestone acceptance.

The provider picker is Meta, then Other compatible API. This is one protocol adapter with explicitly tested capabilities, not a promise that every vendor works. Custom endpoint configuration belongs to the human Settings flow, never a model/tool argument. `AssistantEndpointConfig` native-owned fields: idUUID, base_url normalizedHTTPSstring<=2048 ending `/v1`, hostASCII<=253, port443only, model_idASCII1..96, generationpositiveu64, schema_supportedboolfalse, vision_supportedboolfalse, tested_unixnullableu64. Changed host/port/path resets capability tests, starts newchat, invalidates all outboundconsents and deletes association with the old credential; neverforwardakey to aneworigin.

Refuse any result that is not globally routable unicast: private/loopback/link-local/multicast/unspecified/IPv4-mappedprivate/CGNAT/documentation/reserved ranges; hostname localhost or .local also refused. Disable retries and connection pooling between requests; connection cannot trigger a second unvalidated DNS lookup. Never infer safety from a text prefix or resolve-then-let-client-resolveagain. Standard certificate/hostname validation remains mandatory, TLS>=1.2, no cookies/referer/automaticcompression, endpointmetadata/profile storage contains no key. Test DNSrebinding against a controlled resolver; genericblocklists alone are not proof.
