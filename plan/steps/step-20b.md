Guide only. Write the code and named tests below; do not install, compile, run tests, prototype or launch the app. The coordinator performs shared registration, translations/generation, engine binding, execution and final review. The UI can be authored against20a while the engine decision is pending; production editing remains explicitly unavailable until that binding exists.

## Goal and exclusions

Edit supported documents, format text and paragraphs, manage pages/references/comments/tracked changes, save safely and export PDF through a local approved engine. 20c supplies AI writing actions separately. This step includes17b speech-pack dictation integration below; no network sharing, macro execution, automatic external links or invented full-fidelity guarantee. The Voice group uses17b explicit microphone consent and the Dictation control below; a local **Spelling** control appears in Review only when20a capability spelling is true.

## Decisions

- D1. New handler/controller ID `office-word`; extensions docx/odt/rtf when an approved binding advertises actual preservation, legacy doc and macro-bearing formats remain13 view-only unless separately proved. Coordinator resolves preferred handler/default-app selection with13, not duplicate broad MIME priority claims. Existing read-only opening remains available when engine missing.
- D2. Register one09a controller factory for the handler via20a registerOfficeControllerFactory. Every view obtains the same OfficeController through E8; selection/scroll/ruler/comments panel remain per-view. Enable editing is explicit for protected files. Viewing/reviewing/editing dropdown maps setOfficeMode; reviewing inserts tracked changes and only enables supported review operations.
- D3. Build header40px, ribbon34+112px, page canvas with16px top gap, displayed page640px wide at100%, content padding56/64/48/64 only when the actual document uses that default; do not change imported page margins to match a mockup. Comment cards200px wide, radius8, padding10/12/12,24px author badge; use document page geometry from engine and chrome tokens from app.
- D4. All mutation commands call20a canOfficeCommand, capture current selection/revision once, build one typed DocumentOperation transaction and await it. No active selection or unsupported capability means disabled with reason. Text-format toggles flip definite true/false; mixed toggles set true. Pickers display mixed blank, never apply defaults merely because selection changed.
- D5. New documents use approved engine's blank docx template, body Inter11pt only when licensed Inter asset exists, A4 595.28x841.89pt with20mm margins; fallback font is the approved pack's declared bundled sans, named in its approval manifest. Unsupported font selection is refused, not silently substituted. New calls20a E25 `createOfficeBlankDraft('document')` from `src/services/officeDrafts.ts`, awaits its JobHandle completion and opens the returned shared DocumentHandle/OfficeController. The native09a draft source owns approved encoded DOCX backing and authority; do not invent an untitled path, snapshot identity or separate writable model. Cancel releases only the unacquired native blank draft; after the user edits it, normal09a unsaved-close policy owns its lifetime.
- D6. Heading navigation queries officeItems headings; click changes selection and scrolls to position without edit. Rulers show point-based engine geometry, may drag margins/indent only through typed page/paragraph operations; read-only rulers remain inert. Status shows page/total, word count from typed statistics below, language and zoom; no inferred count from file bytes.
- D7. Comments use OfficeEditComment and typed add/reply/resolve/delete; author is local profile text (default translated Local author). Anchors remain engine positions, not screen coordinates. Track-change accept/reject requires live change IDs; Accept all and Reject all preview current count and confirm. Opened imported comments, replies and review metadata are preserved on round trip.
- D8. AutoSave is per-document, off by default. When explicitly enabled and safe existing-save capability true, debounce2s after last completed edit; serialize saves and capture revision/content identity at dispatch. Failed save keeps dirty state and shows retry; no busy loop. Sensitive inputs use only encrypted provider recovery. Recovery capture2s after last change and on deactivation uses09h registered provider; session JSON never stores text. Save a copy does not clean/rebind the original document.
- D9. Share is local actions Copy file path (disk source only), Save a copy and Export PDF; no cloud upload. PDF capture uses20a exportOffice(format pdf) then08a/09f safe publication, not browser print-to-PDF. Print calls20a E19 printOffice with the capturedrevision and page ranges, using explicit system dialog after capability and page-range confirmation. No silent print.
- D10. Settings schema50 -> 51 adds `document_editor.autosave_default` false, `document_editor.show_ruler` true, `document_editor.show_navigation` false and `document_editor.spelling` true; enabled state still depends on available local checker. Dictation uses17b speech preferences; assistant/backend/model preferences remain17a and AI writing actions20c.

### Dictation and AI writing provider integration

Create src/office/document/DocumentDictation.tsx and src/office/document/documentDictation.ts. Home Voice group includes document.dictation (Mic), label document.dictation “Dictation” / “Dictado”, and stop control document.stopDictation “Stop dictation” / “Detener dictado”; no default shortcut, helpslugdocument-dictation. Enabled only while editable document selection,17b ai_speech capability ready and no active dictation. Start requires an explicit click and native microphone permission, calls17b startDictation(DictationRequest); Stop usesstopDictation(sessionId), user reviews resulting transcript before an atomic20a insert_text at the captured TextPosition/revision. A selection/content change invalidates the insertion preview, not permission to overwrite newer text. Cancel calls cancelDictation and releases data with no document change. This is local speech, independent of17a assistant pack/API backend; no silent cloud microphone route.
