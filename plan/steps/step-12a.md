## Goal and exclusions

Install optional non-AI packs after an explicit choice; inspect and clear every owned data category; control all background work in one place. Do not register AI packs, models or embedding indexes. Windows OCR remains available without these packs. No silent downloads, self-updating executables or changes to the owner's installed programs.

## Read first

## Decisions and algorithms

1. D1. Add a separate signed `pack-catalog.json` plus detached `pack-catalog.minisig`. Verify the exact UTF-8 bytes before parsing; cap catalog at 1 MiB/signature at 8 KiB. Trust the existing public release key supplied to setup verification, never a key advertised by the downloaded catalog. No private-key access. Catalog schema 1; duplicate IDs/versions, unknown mandatory fields, dependency cycles and unsupported schema fail before writing. No network lookup is necessary to open App storage.
2. D2. A catalog is bundled with the app; refresh requires the user choosing Refresh catalog. Sources are explicit HTTPS URLs from its signed allowlist. Reject credentials, fragments, local/private IP destinations and redirects outside the signed HTTPS origin set; no unsigned executable URL from UI. Signed per-file hashes, sizes, licenses and relative entrypoints are mandatory before activation. Artifact hashes are final-build facts, never placeholder zeros.
3. D3. Download to an exclusively created owned partial under `<data>/packs/downloads/<UUID>`. Two downloads maximum, one installation mutation per pack. Resume only with identical URL/version/size/strong ETag and a validated Range response starting at the retained byte offset; otherwise retain the old owned partial until a fresh attempt is accepted, never append mismatched bytes. Pause closes the writer and retains verified ownership; Cancel disposes only its own partial. Full SHA-256 is checked after completion regardless of resume.
4. D4. Guarded ZIP extraction into `<data>/packs/staging/<UUID>`: no absolute paths, parent traversal, drive/ADS names, symlinks/reparse entries or executable callbacks; max 100,000 entries, declared installed size plus 64 MiB, ratio 1,000 and 8 GiB total. Validate every installed file against the signed inventory, reject extras/missing files, flush, then activate a new version by atomic app-state pointer. Never replace an active directory in place. Keep one previous valid version until the new version passes its descriptor/probe checks; failure leaves the old active version unchanged.
5. D5. Pack leases pin a verified version. Update may install beside a leased version; removal marks pending and refuses new leases, cancels queued work, waits for current foreground users to finish or the user to cancel removal. Never kill an unsaved editor silently. Recycle the owned version after all leases close, then update inventory. Pack data is replaceable program/data, never statically linked LGPL code. Offline installers carry the identical signed artifacts; import follows the same verification path.
6. D6. Register IDs `media`, `office`, `ocr` initially; reserve the exact AI IDs from14c ai-runtime-1 below for their producing steps. First-run selected IDs come from setup-core Profile, validated against this allowlist; Reserved AI IDs remain unavailable until their producing capability is registered and its signed artifact is verified; then the same pack manager installs them after explicit user choice. No permanently excluded AI branch remains. Actual pack artifacts are produced/reviewed in 12b; 12a uses a small signed test fixture generated by coordinator with a test key restricted to tests. Production never trusts that key.
7. D7. One storage-provider registry reports physical disk bytes, memory bytes, pending-delete bytes, limits and clear effects. Include cache thumbnails/previews, OCR, filename/content indexes, folder-size/storage scan caches, versions (including pending/open), clipboard, crash logs, downloaded update notes and pack partials. A provider owns its root/handles; UI supplies only category ID. Clear is a job, confirms the exact loss description, never traverses a UI path and never deletes user source files. Leased entries become pending delete; totals remain truthful.
8. D8. Extend 07a BackgroundPolicy, not a new scheduler. Default existing task choices survive. Schema 36 -> 37 adds background.pause_fullscreen true, quiet_hours {enabled:false,start_minute:1320,end_minute:420}, cpu_percent 25 within 5..100, and pack_catalog.last_checked_unix nullable. Quiet hours use current Windows local time; equal start/end means all day when enabled. Explicit foreground jobs bypass idle/AC/quiet-hour policy but always obey Cancel; downloads selected by the user may continue while a background scan is paused.
9. D9. Global Pause all takes effect at the next chunk boundary, at most 100 ms; active background parsers/helpers are stopped or suspended only through their registered cancel/checkpoint protocol, not arbitrary process suspension. Enforce helper CPU limits using Windows job CPU hard-cap information (CPU rate percent multiplied by 100); cooperative native work uses bounded chunks and policy tokens. Cannot claim a CPU percentage was enforced merely by lowering priority. No cloud hydration during background scans.

10. D10. Inject `ProfileRoot` from10c profile-root-1: pack versions/downloads/staging/catalog live under shared_packs_dir (base/packs), not per-profile packs. Profile-owned stores report profile_dir data; shared packs reported once separately, not once per profile. Profile switching cannot uninstall another profile's leased engine. Preserve pre10c legacy data-root meaning; never guess a new AppData location.

### Reserved Office read bridge capability

The office pack reserves capability/entrypoint office_read_bridge for12b E7/13, using the fixed office_read_v1 protocol specified there. It is distinct from ordinary office conversion and is not activated by12a's test fixture. Packs.acquire(PackId::Office,"office_read_bridge") fails packs.capability_missing until the coordinator builds, audits and signs a real bridge with exact entrypoint/hash/license manifest. A bare LibreOffice executable or guessed UNO method is not this bridge. T1/T3 tests reserved_bridge_without_signed_entrypoint_unavailable, wrong_bridge_protocol_refused and active_bridge_retains_exact_pack_version. No production artifact hash is invented in the guide.
