# Step 10b: Customization, round 2: folders, menus, Home, sidebar, status bar, and setups (★★★)

**Needs:** 10a. **Builds:** folder customization, menu editor, setup files.

## Tasks
- **Folder colors and icons:** right-click a folder > "Customize folder" to give it a color (preset palette plus custom), a different icon (from the icon pack, an emoji, or my own image), or both. Shown everywhere in the app: lists, Column view, the navigation pane, breadcrumbs, and tabs. Stored in the app's database (not inside the folder), following the folder when it's moved or renamed inside the app, and optionally applied to Windows Explorer too (via `desktop.ini`, only if I turn that on). Works on several folders at once; "Reset" removes it.
- **Folder backgrounds:** in "Customize folder", optionally a background for that folder's file list: a solid color, a gradient, or an image (fit, fill, or tile), with adjustable opacity and blur so text stays readable (the app checks contrast and adds a dimming layer if needed). Choose whether subfolders inherit it. Off by default; a global switch in Settings > Views hides all folder backgrounds. Images are downscaled and cached so they never slow down opening the folder.
- **Columns per folder type (manual, off by default):** every folder uses the regular columns (Name, Date modified, Type, Size) unless I turn on "Columns per folder type" in Settings > Views. Then I can create column sets (for example Photos: Name, Date taken, Dimensions, Camera; Music: Title, Artist, Album, Duration; Documents: Name, Author, Pages, Date modified) and assign them myself to a folder, a folder and its subfolders, or a folder type. Nothing is detected or applied automatically unless I explicitly choose "Suggest column set" for a folder. Column metadata loads in the background and never slows down listing.
- **Edit the right-click menu:** a visual editor (Settings > Menus) for the file, folder, empty-space, tab, and tab-group menus: show, hide, reorder, group into submenus, add separators, and choose which items appear directly versus under "More". "Reset to default" per menu, with a live preview. Commands removed from menus stay available in the command palette.
- **Customizable Home page:** choose, reorder, and resize sections: Quick access, Recent, Favorites, Saved groups, Storage summary, Pinned searches, Recent conversions (Tagged files is added in Step 11b); collapse or hide any; choose how many items each shows and the card size; drag sections in an "Edit Home" mode. The Figma layout is the default. Sections are registered through a small Home-section registry so later steps can add more.
- **Customizable navigation pane (sidebar):** reorder or hide sections and items (Home, Gallery, pinned folders, This PC, Network, Saved groups, and later Views and Tags), add custom sections with my own folders, rename items (display name only), choose icon size and row spacing, set width and auto-collapse.
- **Customizable status bar:** choose and reorder items for Explorer tabs (item count, selection count and size, free space on the drive, view buttons) and for each file type (page and word count, cursor position, encoding, zoom slider, accessibility check, image size); or hide it entirely.
- **Shareable setups:** export any combination of theme, layout, menus, toolbars, navigation pane, Home page, status bar, keyboard style, and custom shortcuts as one `.adperastra-setup` file (a zip with JSON and images), with a preview and a list of contents before importing; choose which parts to import; personal data such as recent files, paths, or history is never included unless I tick it. Imported setups can't run code.
