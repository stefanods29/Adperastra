Adperastra 0.1.0 - portable
============================

This release is unsigned. Windows may show "Windows protected your PC".
Verify the downloaded ZIP against SHA256SUMS.txt from the same release
before choosing "More info" and "Run anyway".

Unpack the ZIP into a folder where you can write, then start Adperastra.exe.
The app keeps its data in AdperastraData beside the executable. Close the app
before copying the whole portable folder to another drive, and copy the whole
folder, not only the executable. A read-only folder asks for another data
location. Updates are optional and never install automatically.

Adperastra 0.1.0 - portátil
==========================

Esta versión no tiene firma de código. Windows puede mostrar «Windows protegió
su PC». Verifica el ZIP descargado con SHA256SUMS.txt de la misma versión antes
de elegir «Más información» y «Ejecutar de todas formas».

Extrae el ZIP en una carpeta donde puedas escribir e inicia Adperastra.exe.
La aplicación guarda sus datos en AdperastraData junto al ejecutable. Cierra la
aplicación antes de copiar toda la carpeta portátil a otra unidad y copia la
carpeta completa, no solo el ejecutable. Una carpeta de solo lectura pide otra
ubicación para los datos. Las actualizaciones son opcionales y nunca se
instalan automáticamente.
